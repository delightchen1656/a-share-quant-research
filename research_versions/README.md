- 保留可直接代表策略版本、平台版本、模型训练版本或一轮明确研究方向的源码。

- 不恢复回测输出、逐日净值、交易流水、参数缓存、模型缓存、下载器、审计器、构建器、测试器和一次性汇总脚本。
