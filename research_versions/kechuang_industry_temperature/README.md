# 科创行业轮动与温度门控版本

本方向记录从行业分组轮动到科创2-1、2-2的研究收敛。当前正式科创2-2及其必要温度构造位于 `strategies/kechuang/`。

| 代码 | 对应策略或思路 |
|---|---|
| `research_group_rotation_10_variants.py` | 低温复苏、行业动量、双重动量、残差动量、低波趋势、宽度确认等10种分组轮动 |
| `research_temperature_overlay_10_gates.py` | 冰冻排除、升温、复苏、宽度、联动、龙头、高温转弱等10种温度门控 |
| `research_temperature_6_frozen_routes.py` | 三条收益线与三条回撤线的冻结比较；升温放宽防守路线胜出 |
| `baseline_2_1_temperature_attack.py` | 科创2-1：温度概率重排与高温转弱保护，偏进攻 |

正式2-2选择“升温为主、强势行业小幅降温仍可进入”，而不是简单追逐最热行业。内嵌季度熊市模型的历史有效期截至2026-09-30，第四季度使用前仍需更新或核对。
