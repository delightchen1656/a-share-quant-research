# 科创策略向沪深迁移实验

| 代码 | 对应策略或思路 |
|---|---|
| `migration_stop_filter_1_2.py` | 将科创1-2的事件与止损过滤逻辑迁移到沪深股票池 |
| `migration_rising_defense_2_2.py` | 将科创2-2的熊市和行业升温防守逻辑迁移到沪深股票池 |
| `migration_high_attack_3_1.py` | 将科创3-1的高进攻与强势延持逻辑迁移到沪深股票池 |

三份文件是历史平台移植实验，不是沪深正式基准，也不改变“沪深1为R08”的当前定义。它们保留的价值是比较同一策略逻辑在不同股票池、交易口径和平台限制下的实现差异。
