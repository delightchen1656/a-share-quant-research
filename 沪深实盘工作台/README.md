# 沪深实盘工作台 · 沪深1/2

本目录是沪深2晚间工作台的独立运行副本。代码、三份模型、当前登记、运行时、风险复算依赖、UI、测试以及本地账本历史都保存在本目录；行情只读访问仓库公共沪深日线库和 `K线数据/更新备份与审计/` 审计。

当前策略血缘为：原 `C04_NEW` → ATR≥2.5% → P12 → 撤销P12的规模/波动条件并回到ATR-only。现行软件只执行原每日前三之后的 `ATR≥0.025` 过滤，不递补、不重排，不重训模型。P12代码和登记只保存在 `history/source/`，不参与运行。

## 目录

晚间工作台顶部可切换沪深1与沪深2。沪深1入口为 `/hushen1`，实现 `tracker/hushen1.py`，账户资产独立保存在 `tracker/hushen1_data/`；沪深2继续使用原 `tracker/data/`，两个系统不共用现金、成交或持仓。
沪深1初始10,000元空仓，最早2026-10-29记录实际买卖。沿原四因子、5只目标、98%、20交易日相位、缓冲1.5、整手与成交量限制；不连接券商，不会把预案当作成交。晚间只冻结排名与按前收盘价的股数预案，开盘价未知；次日可填写实际开盘价复核并冻结目标，卖出确认到账后再买入，未成交目标延续。实际费用以录入的券商成交记录为准，0.2%仅作限价参考。
1万元账户的整手取整可能显著降低实际仓位，不为凑满98%改变原规则。两个系统每日更新分别维护自身缓存，沪深1仅复用已成功提交的公共行情，不额外启动行情更新。`hushen1_data/ledger.sqlite3`、signals、backups与审计记录是账户资料，不是可清理缓存。原 `沪深1研究/tracking/` 独立本地模拟不被接管或重写。

沪深1常用录入为5只目标的成交价格输入框：只填已实际成交股票的均价，空白不记账；日期与当前计划股数自动带入，预览后须确认股数与券商实际一致。部分成交、实际费用可展开修改。费用缺省按佣金万三最低5元、卖出印花税0.1%估算，在账本标为“预估”；实际成交价不重复加滑点。整批先校验后原子提交，重复或过期预览会拦截。未提供实际开盘价时，默认数量仍基于当前可见收盘价预案，不能称为精确复现开盘股数；高级开盘复核及完整补录入口保留。

- `CURRENT_SELECTION.json`：当前唯一登记。
- `runtime/`：冻结构建器和ATR-only过滤。
- `model/`：utility、pen025、pen100冻结模型及来源清单。
- `tracker/`：本地服务、UI、账本、测试和安装脚本。
- `tracker/data/`：实际软件历史、SQLite账本、缓存和备份；不得作为缓存删除。
- `backtest/`、`results/`：登记自检所需的最小风险复算依赖。
- `history/`：ATR、P12及回退过程的历史源码副本，不参与当前运行。
- `reference/`：当前单元测试所需的三份原始冻结构建函数副本，不从仓库归档导入。

## 验证与运行

```powershell
& .\quant_env\Scripts\python.exe -B .\沪深实盘工作台\verify_package.py
& .\quant_env\Scripts\python.exe -B -m unittest discover -s .\沪深实盘工作台\tracker -p 'test_*.py'
& .\沪深实盘工作台\tracker\install.ps1
```

安装脚本会把桌面“沪深2 星轨”快捷方式和 `Hushen2_Orbit_1830` 任务切换到本目录。软件不连接券商，也不自动下单。

止盈止损使用券商联动单：录入卖出后不再生成清理另一侧卖单的待办。部分卖出仍提示为剩余持仓确认保护，旧清理记录保留。

运行进度显示六个阶段、行情文件处理数、当前模型、累计与阶段用时；完成时明确提示推荐就绪。预计剩余时间只参考本机上一次完整计算记录，首次不估算。当日冻结信号复用不替代完整计算的计时样本。

次日信号生成另有动态进度条，每3秒读取后台状态，录入窗口打开时也继续刷新进度而不重绘表单。进度按已完成步骤和实际文件/模型计数推进，不代表耗时比例；评分内部暂时无计数时显示动态光带，只有就绪后到100%。

沪深1的“每日收益追踪”位于独立持仓下方，复用沪深2日历样式：红盈绿亏、逐月查看、点击日期查看收盘权益/净入金/盈亏/当日成交与费用。可切换累计盈亏、总资产及扣除入出金权益折线，按正式交易日等距显示。每天复用已事务提交并通过审计的未复权K线，页面打开时最多约30秒刷新；不自动下载行情或补造成交。历史补录、冲正按实际日期重算。入出金不计盈利，现金差额更正计入盈亏；旧未分类调整和缺失持仓收盘价显示待核对，缺失区间不连线。分红、送转只按已录入的真实到账现金与股份计算，须人工补齐。该收益是已录账户的日线收盘估值，不是券商盘中净值；关闭软件时不后台运行，下次打开复算。
