# 星轨运行说明

本目录是根目录 `沪深实盘工作台/` 的当前运行层。现行推荐规则只有一项附加过滤：原冻结每日前三之后保留 `ATR≥2.5%` 的候选；不递补、不重排，不使用P12规模代理或60日波动条件。

## 每晚流程

1. 读取已经由 `tools/daily_market_update.py` 成功提交的沪深日线与审计。
2. 如有已经历交易日的有效买单，先逐单选择“买入成功（填写本次股数、均价与费用）”或“今日未成交／跳过”。未成交仅保存核对记录，保留现金、槽位和原7自然日截止日，不等于撤单。部分成交或到期买单仍须明确核对剩余委托。
3. 买单结果全部处理后，再直接覆盖券商现金、复核总权益。后端也会拦截绕过顺序的推荐生成和确认。
4. 使用本包冻结代码、模型和登记生成0—3只新推荐。
5. 用户人工接受或拒绝；软件不连接券商、不自动下单。
6. 持仓止盈、止损和到期退出均由软件提示、用户实际执行并回填。

今晚刚接受、尚未经历下个交易日的买单不要求提前核对。休市期间按最近已完成交易日核对，不凭周末补造成交；未成交核对在19:00后至次日开盘前办理，实际成交仍可随时补录。每天开始新交易日后，仍有效的旧买单重新进入待办。没有待核对买单时直接从资金复核开始，满槽也不能跳过旧买单结果。

`data/ledger.sqlite3`、`data/backups/`、历史信号缓存和观察记录是软件历史，不是缓存。新包首次接管前后不得同时运行旧路径和新路径的两个后台，以免产生两份账本分支。

## 中文路径与计算状态

每次模型成功完成后，原子保存到`data/latest_model_result.json`，并保留按日期/规则命名的冻结信号文件。重开软件优先读取固定结果文件，校验行情日期、完整输入来源、模型/规则指纹及信号内容后复用，不再调用历史特征与模型评分。新交易日行情才产生新一轮计算；同日指纹不符或文件损坏仍停止核查，不能把旧信号冒充新信号。资金、挂单接受/拒绝等账户变化不使模型结果失效，账户门禁照常执行。写入中断保留上次成功文件，未完成的计算不标记为成功。

用户于2026-10-30改回成交价锚：止盈为实际成交均价×(1+4×信号日冻结ATR比例)，止损为实际成交均价×(1−1.5×冻结ATR比例)，目标价取到分。参数卡和持仓的带符号价差为“目标价−实际成交均价”，百分比也以该均价为分母；手续费不进入均价。模型原买入线保留用于对照与买单触发，不再作为止盈止损锚。确认过的卖单价位与新口径不符时提示重新核对，新确认记录保存明确目标价。不改现金、股份或历史成交，不自动更改券商委托。

冻结模型由 `model_loader.py` 使用Python读取原始字节、校验登记SHA-256，再以UTF-8模型文本交给LightGBM，不把中文文件路径传入其原生文件接口。三份模型、特征顺序和预测算法不变；模型缺失或哈希不符仍立即停止，不下载、不重训、不回退到其他模型。加载器代码纳入每日信号来源指纹，旧冻结信号不自动覆盖。

计算期间展示行情校验、特征进度、逐个模型预测等阶段；失败后明确显示“失败（已停止）”，不把后台重试或上次错误冒充已完成的新推荐。

后台新推荐进度每3秒从实际计算任务读取：历史特征每完成20个行情文件上报（短历史文件也计入），每个冻结模型每完成50000行评分上报。总条按阶段工作量加权，模型逐行独立的预测结果与原一次性预测逐值一致；百分比不是用时比例，只有推荐正式发布才为100%。合并、横截面排名和完整性核验期间显示真实阶段与耗时，不用计时器伪造处理数量。
