# 科创板关联组中长期轮动：本地基准 v1

本策略只使用截至信号日可见的数据。每月首个交易日收盘后，用过去252日收益相关性对当时满足上市满120日、20日平均成交额不低于5000万元的科创板股票做层次聚类，形成12个“关联组”。这比使用今天的静态行业标签回填历史更能避免行业分类的未来信息。

每个关联组用当前成员历史日收益的等权平均构造指数，观察最近520日的价格区间分位、60日动量、120日均线及站上均线的成分股比例。指数位于区间60%以下、趋势转正且市场宽度不弱时可买；指数进入85%以上后动量减弱，或跌破120日均线3%，则退出候选。

每月最多选择评分最高的3组，每组选3只“60日动量较强、120日波动较低、流动性较好”的股票，最多9只，次日开盘交易。执行遵循项目的科创板本地规范：T+1、买入至少200股、停牌及一字板过滤、单边0.1%滑点、成交量25%上限、佣金万三且最低5元、过户费十万分之一、卖出印花税分时段处理。

运行：

```powershell
..\quant_env\Scripts\python.exe backtest.py
```

输出位于 `outputs/`。该版本是用于验证思路的研究基准，不是经过调参挑选的最优策略。

十方向公开方法研究由 `research_variants.py` 运行，完整比较见 `TEN_VARIANTS_REPORT.md`，机器可读结果位于 `outputs/variants/`。

固定行业每日温度由 `temperature_variants.py` 构造；以温度作为基准1-3行业确认层的十方向完整撮合由 `temperature_overlay_backtest.py` 执行，结果见 `TEMPERATURE_OVERLAY_REPORT.md`。

收益前三降回撤、回撤前三增收益的六版本研究由 `optimize_six_temperature.py` 执行，三个1000万元起点结果和成败判断见 `SIX_OPTIMIZED_REPORT.md`。
