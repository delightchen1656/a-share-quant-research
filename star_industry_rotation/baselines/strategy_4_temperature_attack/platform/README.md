# 基准2-1：温度进攻——SuperMind平台版

上传文件：`supermind_strategy4_temperature_attack_single.py`。模型、615只股票行业映射和温度代码均已内嵌，不需要上传附件。

平台设置：

- 股票策略；
- 运行频率：每日；
- 回测区间：2020-01-01至2026-07-31；
- 基准：科创50 `000688.SH`；
- 初始资金：先用100万元对齐，再跑1000万元；
- 成本场景：代码默认`neutral`，约单边0.20%不利滑点，另计万三佣金、最低5元；
- 熊市模型有效期：2026-09-30，进入2026Q4前需要重新训练更新。

本基准继承基准1-1至1-3全部逻辑，在盘前使用263根已完成日线计算固定行业温度。行业温度达到85且10日温度斜率为负时拒绝新仓；熊市概率达到70%且温度变化低于-5时拒绝新仓。

第一次平台回测后请导出收益概览、交易明细、历史持仓和日志，不能把本地54.36%年化直接视为平台结果。
