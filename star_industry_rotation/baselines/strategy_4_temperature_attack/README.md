# 基准2-1：温度进攻

正式名称：**基准2-1：温度进攻**。

这是双基准中的进攻版本。底层使用基准1-3熊市分散主力建仓候选；行业层使用固定行业每日温度，排除高温转弱行业，并仅在极端熊市概率下增加温度斜率保护。

固定规则：

- 行业温度达到85且10日温度斜率为负时，拒绝该行业新仓；
- 市场熊市概率达到70%且行业10日温度变化低于-5时，拒绝新仓；
- 其余候选沿用基准1-3熊市分散版本的排序、仓位、止损、分批止盈和最长持有规则；
- 后续研究不得直接修改本目录，变化必须建立新基准编号。

100万元、2020-01-01至2026-07-31：年化54.36%，最大回撤-30.35%，期末1737.30万元。

1000万元从2020年进入：期末1.7290亿元，年化54.25%，最大回撤-30.78%。

本地研究引擎尚未强制单日成交量25%上限，1000万元结果属于日线容量近似。
