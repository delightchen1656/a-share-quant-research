# 基准2-2：升温防守

正式名称：**基准2-2：升温防守**。

这是双基准中的稳健版本。底层使用基准1-3熊市分散主力建仓候选；行业层原则上只允许温度正在上升的行业开新仓，同时允许温度较高、市场宽度较强且只有小幅降温的行业继续进入。

固定规则：

- 行业10日温度斜率大于0时允许新仓；
- 或行业温度不低于65、10日温度变化高于-4且至少55%成分股站上60日均线时允许新仓；
- 其余候选沿用基准1-3熊市分散版本的排序、仓位、止损、分批止盈和最长持有规则；
- 后续研究不得直接修改本目录，变化必须建立新基准编号。

100万元、2020-01-01至2026-07-31：年化33.11%，最大回撤-14.55%，期末655.78万元。

1000万元从2020年进入：期末6374.97万元，年化32.53%，最大回撤-14.56%。2026年进入至2026-07-31收益-0.42%，最大回撤-10.69%。

本地研究引擎尚未强制单日成交量25%上限，1000万元结果属于日线容量近似。
