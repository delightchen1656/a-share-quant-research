# Sharpe 1.0持续迭代：第一批结果

更新时间：2026-09-14

## 目标与口径

目标为成本后全周期Sharpe达到1.0。继续强制采用T日信息、T+1执行、停牌和一字板限制、单边0.3%成本，并分别报告2018—2023、2024、2025—2026/08。当前尚未达标，不以局部区间或删除亏损年份冒充完成。

## 当前最好结果

`Q3-G7 + 特异波动倒数权重 + 18%组合波动目标/40日检查`：

| 指标 | 结果 |
|---|---:|
| 年化收益 | 11.32% |
| 最大回撤 | -20.92% |
| Sharpe | **0.759** |
| 平均仓位 | 90.88% |

相对本轮开始时Q3-G7约0.705 Sharpe已有提升，但距离1.0仍差0.241。

## 关键发现

1. 当前可盈利策略高度依赖同一类低波/反转风险，简单组合不会显著提高Sharpe。
2. 逆特异波动权重是有效结构改进：年化约12.19%、回撤约-23.55%、Sharpe约0.730。
3. 18%波动目标在40日才调整一次，可以把回撤进一步降到约-20.92%，Sharpe升至0.759；更频繁调整因成本反而变差。
4. 单股二级模型有预测能力但没有经济收益，不能再沿该目标继续调参。
5. 要达到1.0，需要引入与主板反转真正低相关的收益源；继续在同一批股票上做权重混合，数学上很难跨过目标。

## 后续路线

下一批优先顺序：

1. 利用现有指数数据构造不做空的股票/指数状态轮换，现金状态计入保守收益假设与零收益双口径；
2. 检查不同市值与流动性层的反转是否存在错位，形成互不重叠的子池，而不是同一股票重复打分；
3. 构建组合级下行风险预测，只预测未来波动和回撤，不预测个股收益；
4. 对达到或接近1.0的候选执行逐年、去除最佳日和真实现金撮合复核。
