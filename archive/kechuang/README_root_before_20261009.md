五个基准共同遵守一条交易纪律：**只能使用下单时已经获得的数据；严格遵守A股T+1、停牌、涨跌停、最低买入数量、现金和成交容量约束，未成交订单不得按理论成交记账，研究候选不得自动覆盖正式入口。**

## 保存原则

- 当前可运行入口、模型训练源码、模型实物和受保护行情完整保留。
- 历史中能代表策略版本、冻结候选或明确研究假设的代码保存在 `research_versions/`。
- 每个研究方向只用一份Markdown概括代码、策略、研究思路、结论和限制。
- 中间构建器、下载器、审计器、临时分析器、缓存、日志和大批量回测输出不进入版本归档。
- 历史代码可能依赖旧路径或已删除数据，仅用于追溯；不能把它当作当前入口。

恢复代码的索引见 `research_versions/README.md`。当前基准研究史从 `strategies/kechuang/HISTORY.md` 和 `archive/hushen/20261008_before_unification/HISTORY.md` 进入。
