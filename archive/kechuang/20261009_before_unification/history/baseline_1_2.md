# 科创1-2：止损过滤研究路线

状态：正式基准，已冻结。平台入口：`../supermind_baseline_1_2_stop_filter.py`。

## 研究目标与模型

科创1-2从早期“异常上涨前建仓”事件模型演进而来。主模型使用18项过去60个交易日价量特征，识别未来20个交易日内最高价上涨30%的机会；在此基础上新增第二个分类模型，预测未来22个交易日内是否先触及-7%止损而不是+24%止盈。

最终只保留 `stop_probability <= 0.50` 的候选，排序分数为 `上涨概率 - 0.22 × 先止损概率`。原有每日最多8个候选、最多14只持仓、单票目标10%、-7%止损、+24%减半、+34%清仓和30自然日到期规则保持不变。

## 尝试过的方向

| 方向 | 结论 |
|---|---|
| 先止损概率过滤 | 唯一同时提高全周期年化并降低回撤的方向，正式采用 |
| 盈利后移动止盈 | 有改善但没有形成更优综合前沿，未采用 |
| 科创普跌广度过滤 | 回撤收窄、收益下降，保留为历史思路 |
| 波动率反向仓位 | 有一定风险改善，综合收益不足 |
| 机会质量控制仓位 | 收益与回撤改善不稳定 |
| 组合回撤限制新增仓位 | 风控明显，但收益损失过大 |
| 高相关候选去重 | 未改善核心回撤 |
| 高波动信号过滤 | 过滤过强，收益损失大 |
| 连续止损冷却 | 过度抑制交易 |
| 信号拥挤提高阈值 | 设定未有效触发，判为无效 |

三个优胜方向的机械叠加年化仅33.29%，因此没有采用“多规则越多越好”的方案。

## 冻结参考数据

| 口径 | 年化 | 最大回撤 |
|---|---:|---:|
| 2020-01-01至2026-07-31，100万元 | 61.15% | -31.73% |
| 2025-01-01至2026-07-31历史测试 | 29.63% | -30.74% |

与上代基准相比，全周期年化提高0.52个百分点、最大回撤收窄6.03个百分点；历史测试年化提高14.93个百分点、回撤收窄9.89个百分点。10万元结果会受到200股起买和最低佣金影响；1000万元旧研究未完整模拟市场冲击，不能直接解释为实盘容量。
