# 科创3-2：2021年一季度起点敏感性

日期：2026-10-04。仅本地历史回放，未修改3-1或3-2平台源码，未重训或选参。

## 口径

- 2021-01-04至2021-03-31的58个交易日分别空仓投入100万元，统一结束于2026-09-30；不是58天连续追加资金。
- 继承3-2内嵌预测模型及退出函数；逐股抽样检查本地特征与平台函数一致。只使用前一交易日及更早行情发出当日开盘订单。
- 原始价记账、前复权构造信号；使用历史上市/退市日期及可用行情。现金分红、转增按BaoStock原始公司行动记录记账，不将除权参考差额当成实际派息。
- T+1、停牌不成交、开盘涨停不买/跌停不卖，日量25%容量、单次市场订单最多50000股、买入至少200股。先买后卖，无当日重试。
- 每边滑点0.2%，佣金万三最低5元，卖出印花税全期千一；现金分红统一预扣20%。这些是偏保守的本地近似，不是按各历史日期、持有期精确税费结算；未单列过户费。上市特殊无涨跌幅时段不交易（股票池至少120条历史）。
- 停牌持仓沿用最后价格；观察到退市时剩余权益按零核销。订单部分成交、排队和平台委托回调只做本地近似，不代表平台精确复现。

最高期末资产/最低为1.07192倍。年化最低起点2021-01-12，最高2021-03-31（不等同于最高期末资产起点）。年化使用实际日历日长度365.25，较晚开始、相同期末资产自然对应较高年化。

结论：本次第一季度内换起点对长期期末资产影响相对有限，未改变约36%的共同回撤风险。不同起点路径共享几乎全部后续行情，58组不是58个独立样本，不能据此推广到任何年份新开仓都稳定。

## 最重要的局限

继承的旧模型包含2024年以前训练信息，且旧方案曾利用后续历史研究选优。因此2021年开始的回放不是当时真实可部署模型的严格样本外检验；本次高年化不能当作未来收益预期。最新前复权数据、BaoStock与平台数据差异、税费及撮合近似也会影响绝对收益。这里只比较同一固定本地口径下的起点差异，没有证明与SuperMind收益对齐。

公司行动金额与原始除权参考价不一致的事件保存在reference_price_differences.json；688366和688244涉及差异化分红，实际持有人分配与摊薄后的交易所参考价应分开。参考公司公告：[昊海生科2024年年度报告](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=10800502&stockid=688366)、[永信至诚2025年权益分派核查意见](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=11161250&stockid=688244)。数据源缓存原样保留，未修改行情。
