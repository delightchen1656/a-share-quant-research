# 年化收益—Sharpe归一化综合损失

研究日期：2026-09-11。目标是解决“Sharpe与年化收益量纲不同，单独优化Sharpe会过度牺牲收益”的问题。候选池为前两轮全部不重复方案，共56个。

## 损失函数

每个区间分别对年化收益率和Sharpe做5%—95%分位缩尾Min-Max归一化：

```text
N(x) = clip(x, Q05, Q95) - Q05
       -------------------------
              Q95 - Q05
```

区间效用强调年化收益：

```text
U_period = 0.75 × N(CAGR) + 0.25 × N(Sharpe)
```

综合效用及损失：

```text
U = 0.40 × U_design + 0.60 × U_recent
    - 0.20 × abs(U_design - U_recent)

Loss = -U + ConstraintPenalty
```

- `design`：2020—2024。
- `recent`：2025—2026/7，权重更高是为了强调靠近实际使用期的表现。
- 稳定性惩罚防止候选只在一个区间异常突出。
- 设计期、近期、全周期任一区间最大回撤不在10%—50%内，约束罚分为10，相当于直接淘汰。
- 归一化边界只用于候选间可比，不改变原始年化和Sharpe。

## 结论

在“年化明显优先，但不放弃Sharpe”的损失下，综合第一为80%基准3-1＋20%基准2-2。相比基准3-1：

- 全周期年化：72.75%降至64.59%，代价8.16个百分点；
- 全周期Sharpe：1.99提高至2.05；
- 最大回撤：-35.28%改善至-29.71%；
- 近期年化：53.29%降至45.63%。

如果唯一目标是年化最高，基准3-1仍然第一；综合损失的意义是选择“少牺牲收益、明显改善风险质量”的点。当前80/20仅是组合层候选，尚未经过单账户逐笔合并撮合，不能直接晋升正式基准。
