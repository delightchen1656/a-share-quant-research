# 公开思路与新增结构的Sharpe优化

研究日期：2026-09-11。底层收益源保持为正式基准3-1“强势延持”和基准2-2“升温防守”。本轮不是阈值网格调参，而是测试12个彼此不同的组合结构。

## 研究依据

- Moreira 与 Muir 的波动管理研究指出，高波动时降低风险敞口可以提高多类权益因子的Sharpe。
- Bongaerts、Kang 与 van Dijk进一步指出，普通连续波动目标并非在所有市场都有效；只在高、低波动极端状态调整的条件波动目标，可能以较低换手改善尾部风险。
- 相关性聚类和过滤研究提示，表面上持有多个标的或策略不等于真正分散；相关性在压力期上升时应控制共同风险暴露。
- 公开研究只提供方向，不直接照搬结论。本报告全部数字来自本项目A股本地数据。

## 严格口径

- 设计期：2020—2024；近期检验期：2025—2026/7；全周期：2020—2026/7。
- 所有波动、趋势、回撤、相关性和收益动量只使用前一交易日及更早数据。
- 不使用杠杆，空余仓位收益记0；底层策略成本已包含，组合敞口及权重变化另扣单边0.10%。
- 合格条件：三个区间最大回撤绝对值均在10%—50%。主排名按 `min(设计期Sharpe, 近期Sharpe)`，避免只追逐近期最优。
- 本轮结构是预先定义的单点规则，不在同一方向内扫描参数。

## 判断

1. **Sharpe优先的新候选：条件波动极端管理。** 50/50核心平时维持敞口，只在过去252日中的波动分位进入最高20%时降至55%，进入最低20%时保持85%。它的稳健Sharpe为2.031，略高于上轮稳健冠军2.030；全周期年化提高约3.91个百分点，回撤也略低。
2. **收益与风险折中：回撤迟滞恢复。** 80/20进攻核心在回撤8%和15%时分级减仓，并在回撤恢复到3%以内后才恢复满敞口。它没有上轮高收益折中的全期年化高，但近期Sharpe更好，体现“慢恢复”确实减少反复加减仓。
3. **当前提升真实但很小。** 第一名相对上轮稳健冠军的最低分段Sharpe只提高约0.0015，不能凭这一点宣布统计显著胜出。更合理的结论是它提供了更高全期年化和相近回撤，值得进入合并逐笔撮合，而不是直接晋升正式基准。
4. 最小方差月配在设计期Sharpe最高（2.27），但近期降至1.64，说明基于历史协方差的权重在状态变化后不稳定；不选它。
