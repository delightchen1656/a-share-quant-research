# 基准1-2、2-2、3-1迁移沪深主板顺序开发报告

> 执行状态（2026-09-14）：M1—M6已完成。结果归档于`execution_20260914/`。基准2-2因只有当前行业映射，仍为功能验证版本。

版本：V1.0
制定日期：2026-09-12
当前状态：规则迁移测试版已生成；主板数据尚未下载；禁止宣称模型已经适配主板。

## 1. 项目目标

将现有科创板三套策略迁移到沪深主板：

1. 基准1-2：止损过滤；
2. 基准2-2：升温防守；
3. 基准3-1：强势延持。

迁移后的策略必须满足：

- 只使用信号时点已经可获得的数据；
- T日收盘后生成信号，T+1才允许买入；
- 使用不复权价格成交和结算，使用前复权价格计算特征；
- 模拟100股整数手、停牌、ST、涨跌停、T+1、费用、滑点和成交量约束；
- 2015—2024用于训练和设计，2025—2026/7作为锁定的独立测试；
- 科创板正式基准和历史结果保持冻结，主板版本独立编号和归档。

第一目标不是让主板结果追上科创板历史收益，而是确认原有“异常拉升前建仓”逻辑在主板是否存在可重复、可成交的样本外优势。

## 3. 数据下载方案

### 3.1 日线文件

每只股票保存两套日线：

- `raw`：不复权，用于成交、涨跌停和资金结算；
- `qfq`：前复权，用于收益率、均线、振幅、回撤和机器学习特征。

必需字段：

```text
date, symbol, open, high, low, close, preclose,
volume, amount, turnover_rate, pct_change,
trade_status, is_st, adjust_factor
```

时间范围：

```text
2015-01-01 至数据源当前可获得的最后日期
```

必须分开保存原始数据和派生数据，不允许用复权价格直接计算下单数量或成交金额。

### 3.2 证券状态

必须保存：

- 上市日期、退市日期；
- 每日ST和`*ST`状态；
- 每日停牌状态；
- 股票名称历史变化；
- 除权除息与复权因子；
- 涨停价、跌停价或可复现的计算依据。

历史回测使用当日真实存在的证券集合，不能用2026年的存续股票反推2015年。

### 3.3 行业与指数

基准2-2需要申万一级或二级行业及其历史归属。只有当前证监会行业大类时，可以先做功能验证，但不能作为最终行业升温模型。

同步下载：

```text
000300.SH  沪深300
000905.SH  中证500
000852.SH  中证1000
000001.SH  上证指数
399001.SZ  深证成指
```

### 3.4 下载完成验收

- 每个交易日能够恢复当日真实股票池；
- raw与qfq的股票、日期覆盖能够对齐；
- 价格、成交量和复权因子无大面积缺失；
- 随机抽取不少于30只股票与同花顺核对；
- 除权日前后收益连续，真实成交价仍保持不复权；
- 缺失、重复、异常价格和失败任务形成独立报告。

## 4. 数据集与标签开发

### 4.1 特征

第一轮保留原18项技术特征，不引入财报：

- 5、20、60日收益；
- 20、60日价格区间；
- 20日回撤；
- 20、60日波动率；
- 量比、成交量离散度；
- 上涨日成交量占比；
- 量价相关性；
- 60日价格位置；
- 20日换手率与成交额；
- 突破幅度、距60日低点涨幅、成交量异常。

特征只能使用信号日收盘及更早数据。

### 4.2 暴涨标签

同时统计但不混合两个标签：

```text
Label A：未来40个交易日最高价相对信号日收盘上涨30%
Label B：未来60个交易日最高价相对信号日收盘上涨30%
```

第一轮用Label A复现原策略；如果正样本过少，再把Label B作为独立迁移版本，不能测试后随意替换标签。

统计内容：

- 每年正样本数量和正样本率；
- 沪市、深市及三个Pool分别统计；
- 行业分布、月份分布和连续涨停依赖度；
- T+1涨停导致不可买入的正样本比例。

### 4.3 先止损标签

按真实路径定义：

```text
T日收盘产生信号；
T+1可成交开盘价作为入场价；
未来22个交易日先触发-7%，还是先触发+24%。
```

必须排除T+1一字涨停无法买入的样本。若同一日高低价同时触及止损和止盈但没有分钟数据，采用保守顺序：先止损。

## 5. 模型训练顺序

### 阶段1：主板暴涨模型

1. 分别训练Pool A、B、C；
2. 训练截止2024-12-31；
3. 使用时间切分和标签期purge，避免相邻样本泄漏；
4. 沪市、深市先统一模型，同时记录分市场指标；
5. 如果两市场概率校准明显不同，再训练独立模型；
6. 输出AUC、PR-AUC、Precision、Recall、信号数量和概率校准曲线。

验收门槛：

- 2020—2024验证期Precision至少20%；
- 信号不能集中在单一年份或单一行业；
- 2025—2026/7测试前锁定模型、特征、标签和阈值。

### 阶段2：主板先止损模型

1. 使用已成交定义的数据训练；
2. 只使用信号时点可得特征；
3. 比较有无止损过滤后的Precision、收益和回撤；
4. 概率阈值初始保持0.50；
5. 阈值只能在2020—2024确定。

### 阶段3：概率阈值校准

主信号阈值不默认沿用0.63。以2020—2024为设计区间，建立：

- 标准档：Precision约20%；
- 保守档：Precision约25%；
- 极保守档：Precision约30%。

在满足Precision条件时优先保留更多信号，并检查每天最多8只、最多持仓14只是否构成容量瓶颈。

## 6. 三个策略的迁移顺序

### 6.1 第一套：主板基准1-2 止损过滤

这是主板研究的基础版本：

- 主板暴涨模型；
- 主板先止损模型；
- 风险调整排序；
- 30自然日到期；
- `-7% / +24%减半 / +34%清仓`。

先完成它，其他两个策略才能获得统一对照。

### 6.2 第二套：主板基准3-1 强势延持

在主板基准1-2上只增加：

```text
持有满30自然日且盈利不足10%：卖出；
盈利达到10%：允许继续持有；
最长60自然日：卖出。
```

第一轮不改成45/90日。只有确认主板行情确实因上涨更慢而被过早卖出，才单参数测试持仓期限。

### 6.3 第三套：主板基准2-2 升温防守

最后迁移，依赖前两阶段和行业数据：

- 主板暴涨与止损模型；
- 主板行业温度；
- 主板市场广度；
- 主板熊市模型；
- 行业升温或强势时允许新增仓位；
- 熊市概率控制新增仓位比例。

科创板熊市模型和行业温度阈值不能直接当作主板正式模型。

## 7. 统一主板成交规则

| 项目 | 主板规则 |
|---|---|
| 频率 | 日频 |
| 信号与成交 | T日收盘信号，T+1执行 |
| 买入单位 | 100股整数手 |
| 基础仓位 | 10% |
| 小账户动态仓位 | `max(基础仓位, 价格×100×1.01/总资产)` |
| 单票上限 | 20% |
| 最大候选 | 每日8只 |
| 最大持仓 | 14只 |
| 止损 | -7% |
| 止盈一半 | +24% |
| 全部止盈 | +34% |
| T+1 | 严格执行 |
| 涨停 | 不买入 |
| 跌停 | 不卖出，延后处理 |
| 停牌 | 不交易 |
| 价格 | 不复权真实价格 |
| 信号特征 | 前复权价格 |

普通股票追涨过滤初始为`quote_rate < 9.5%`。ST股票直接排除；实时涨跌停状态以平台或数据源提供的涨跌停价为最终依据。

## 8. 本地回测顺序

数据下载完成前不运行本地收益回测。完成后严格按以下顺序：

1. 数据质量与同花顺抽样核对；
2. 标签统计，不训练模型；
3. 训练Pool A、B、C暴涨模型；
4. 锁定最可行Pool；
5. 训练先止损模型；
6. 回测主板基准1-2；
7. 只增加强势延持，回测主板基准3-1；
8. 补齐行业和熊市模型，回测主板基准2-2；
9. 最后一次运行2025—2026/7独立测试；
10. 做100万、10万和1000万资金容量对比。

每个策略必须输出：

- 最终资产、累计收益、年化收益；
- 最大回撤、Sharpe、Calmar；
- 完整交易、胜率、平均单笔收益；
- 止损、24%减半、34%清仓、30/60日到期次数；
- 信号数、下单数、成交数、拒单数；
- 涨停未买、跌停未卖、停牌、资金不足和100股门槛次数；
- 自然年独立回测和不同起始年份持续到2026-07-31的结果。

## 9. 独立测试与晋升条件

2025—2026/7必须保持真正样本外：

- 不重新训练；
- 不改阈值；
- 不改股票池过滤；
- 不根据测试收益选择标签；
- 不根据测试回撤改变止损和持仓期。

主板候选进入SuperMind正式验证至少满足：

- 样本外Precision不低于20%；
- 样本外交易数量足以评估，不依赖少数5—10笔交易；
- 加入中性成本后仍有正收益；
- 回撤不超过预先设定的50%硬上限；
- 没有未来函数、复权成交、涨跌停虚假成交和幸存者偏差；
- 10万、100万、1000万资金下不存在异常成交放大。

达标只代表可以进入模拟盘，不代表可以直接实盘。

## 10. SuperMind交付顺序

1. 先上传规则迁移测试版，确认3193只股票的行情接口、运行时间和平台限制；
2. 检查每日历史行情请求是否超时；
3. 如有必要，盘前静态过滤后再分批计算特征；
4. 本地模型通过独立测试后，将主板模型导出为可移植树结构；
5. 替换规则测试版中的科创模型和行业映射；
6. 进行禁用调用、语法、模型预测一致性和股票池数量校验；
7. 平台跑短区间成交审计；
8. 平台跑完整区间并与本地逐日净值、候选和成交对齐；
9. 归档源代码、SHA256、参数、模型训练期和平台报告。

## 12. 当前结论

最可行的开发路线是：

```text
下载完整主板数据
→ 建立历史时点股票池
→ 优先研究活跃主板Pool B
→ 训练主板暴涨模型
→ 训练主板先止损模型
→ 建立主板基准1-2
→ 增加强势延持形成主板基准3-1
→ 最后迁移行业升温形成主板基准2-2
→ 锁定后测试2025—2026/7
→ SuperMind逐日对齐
```

主板全部3193只可以作为对照，但正式研究应优先使用每日约800—1600只的活跃主板池。这样最符合原策略寻找“尚未启动、但具有异常拉升潜力”股票的特性。
