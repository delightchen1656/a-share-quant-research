# 项目归档

本目录集中保存已经形成稳定结论、需要长期复核的项目材料。

- `baseline_registry/`：五个正式基准的名称映射、总表和本地回测对比。
- `platform_audits/`：平台原始导出、成交审计、组合研究和可复现脚本。
- `PROJECT_STRUCTURE.md`：当前工程目录、入口和维护边界。
- `REORGANIZATION_LOG.md`：目录和名称同步历史。

当前正式名称统一为：基准1-1 暴涨建仓、基准1-2 止损过滤、基准1-3 熊市分散、基准2-1 温度进攻、基准2-2 升温防守。

研究代码仍保存在各自项目目录；归档内容不得直接覆盖，新增实验应先写入研究目录。
