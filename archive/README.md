# 项目归档

`archive/` 保存已经形成稳定结论、需要长期复核但不应继续修改的材料。

- `baseline_registry/`：正式基准名称、状态、关键指标和路径映射。
- `platform_audits/`：平台原始导出、校验值、成交审计和组合分析。
- `optimization_studies/`：未晋升基准的方向研究，以及已停止任务的结论摘要。
- `migration_studies/`：跨市场迁移方案、数据质量检查和阶段验收报告。
- `PROJECT_STRUCTURE.md`：当前文件架构和维护边界。
- `REORGANIZATION_LOG.md`：历次整理与归档记录。

归档目录只追加更正说明，不直接覆盖冻结结果。可再生成曲线、缓存、partial 文件和第三方仓库副本不属于归档。
