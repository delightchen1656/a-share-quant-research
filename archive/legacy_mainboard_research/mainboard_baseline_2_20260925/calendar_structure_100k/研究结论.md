# 固定月历研究：降低了启动日敏感性，但尚未全面胜出

完成336次回测。24个开发起点：2020/2021年1、4、7、10月首个交易日及后移5/10个交易日。24个后段起点：2024年1—8月相同三种移位。每个窗口24个月，初始10万元，目标6只，基础80%仓位。后段是已观察过的历史，不是全新样本外。

## 主要发现

启动日锚定月度的开发年化中位数6.58%、P10为-0.51%、最差窗口回撤23.62%；固定月初版本分别为16.15%、10.60%、18.54%。本轮开发样本已包含移位起点，与上一轮只取月初的17.79%不可直接混比。

按同一入场月份内三个起点的年化最高值减最低值，八组的差值中位数：启动日锚定为17.44个百分点，固定月初为2.08个百分点。最大差值分别25.79和4.31个百分点。这一比较同时改变首次入场及24个月终点，不是纯首次买入价格实验，但后续固定月历明显减少了启动日期带来的路径分叉。

固定11日与21日的开发年化中位数分别8.41%、11.05%，说明具体调仓日期仍然影响结果。不能将固定月初的优势解释为已证明的普遍月初效应。

## 后段及成本验证

| 条件 | 锚定月度年化中位数/P10/最差回撤 | 固定月初年化中位数/P10/最差回撤 |
|---|---|---|
| 2024年起点 | 20.81% / 9.76% / 26.41% | 19.17% / 15.00% / 13.78% |
| 开发期双倍成本 | 3.37% / -3.14% / 27.34% | 12.74% / 7.09% / 19.41% |
| 后段双倍成本 | 17.05% / 6.24% / 26.95% | 15.90% / 11.77% / 15.40% |

固定月初改善了较差起点收益和回撤，但后段年化中位数比对照低1.63个百分点，超过事先允许降低1个百分点的门槛，因此未通过全部晋级条件。未放宽门槛，也未根据后段结果改选其他方向。

固定月初加周度风控开发年化15.66%、P10为9.49%、最差回撤16.82%，值得后续单独检验，但本轮未进入冻结后的验证，不能声称后段通过。

## 实现与限制

立即首轮建仓，之后按固定日历调仓，休市顺延；非月初启动可能很快遇到下一次月初调仓，并非持满一个月。每次使用前一交易日信号。风控只在周一（休市顺延）检查中证500相对60日高点回撤：超过10%限制仓位40%，超过15%限制20%；仅卖出、不换股、不恢复仓位，恢复要等月度调仓。仍有最低调整金额、整手和成交限制，所以不保证实际仓位即时达标。

新增可选卖出风控参数不改变默认回测行为。4项合成测试通过，48个旧对照窗口的年化、回撤、Sharpe回归核验通过。未修改正式平台策略文件。

本地采用日开盘近似；股票池固定，公司行动近似，交易税费沿用本地对齐口径，不代表已经实现逐日历史费率或平台分钟成交复现。双倍成本将佣金、最低收费和滑点翻倍，税率不变。全部指标扣除所建模成本，但并非保证包含所有实盘摩擦。

结论：将固定月历作为下一轮研究基础，比继续优化启动日锚定更有依据；当前仅为研究候选，不自动升级正式沪深基准2。
