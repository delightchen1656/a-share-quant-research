# 方向5：标签定义与可用性审计

本轮完成第10步的标签定义登记，以及第11步的日历、覆盖、缺失原因和名义成熟时点检查。没有生成收益数值，收益分布与实际标签准入仍等待最小成交和记账核验。原研究协议、验收目标和时间划分不变。

## 标签口径

连续排序目标为五个市场交易间隔的税费前经济持有收益：t0收盘形成信号，t1开盘尝试进入，t6开盘尝试退出。条件是两端成交及期间权益处理均已核验；开盘价存在、当天有成交量，都不能单独证明自己的订单成交。

在持仓和事件均有可靠记录的情况下，标签定义为：

`（全部可出售的应得股份退出收入 + 已核实的税前现金分红权益 - 原始进入金额）/ 原始进入金额`

没有期间公司行动且成交核验通过时，才可简化为 `退出开盘价 / 进入开盘价 - 1`。这里没有计算该比值。训练目标采用税费前经济收益，完整账户目标仍按原协议扣除费用、滑点及适用税款；两者不同，不能把训练标签直接当成账户净收益。

权益认定按股权登记日收盘持仓处理：买入日在登记日或之前、卖出开盘日严格晚于登记日，才可能享有该笔权益。卖出开盘与登记日收盘是两个时点。股份调整按普通投资者实际应得比例处理，不按公司总股本增长比例替代。现金应收、实际支付和可支用现金分别记账；未上市的应收股份不得直接假设已经卖掉。配股、重整、定向转增及碎股都需要各自处理。

现金分红的实际扣税与投资者及持股期限有关，供应商的单个税后字段不能替代账户税务处理。历史依据已归档，见[财政部2015年通知](https://www.mof.gov.cn/gp/xxgkml/szs/201509/t20150907_2510529.htm)及[配套政策解释](https://m.mof.gov.cn/zcjd/201509/t20150909_1455696.htm)。开盘成交核验将依照交易机制处理，相关历史说明见[中国证券协会2018年集合竞价说明](https://tzz.sac.net.cn/tzabc/nwwd/201808/t20180807_24767.html)。

计划退出不能成交时，固定五间隔标签保持缺失；账户持仓继续留在账本，按实际退出规则处理。不能悄悄改用延长持有后的收益替代原目标，也不能把未成交记成零收益。

## 覆盖审计结果

保留全部4,382,527条开发期已观察信号记录，原有3,737,172条资格通过记录的标记没有改变。每条记录新增计划进入/退出日、名义最早信息日、数据检查位和缺失原因。

| 年度 | 资格通过记录 | 首轮基础数据候选 | 占资格通过记录 |
|---|---:|---:|---:|
| 2018 | 306,375 | 302,396 | 98.70% |
| 2019 | 657,429 | 643,531 | 97.89% |
| 2020 | 656,560 | 642,793 | 97.90% |
| 2021 | 688,424 | 674,481 | 97.97% |
| 2022 | 714,489 | 700,535 | 98.05% |
| 2023 | 713,895 | 683,006 | 95.67% |
| 合计 | 3,737,172 | 3,646,742 | 97.58% |

“首轮基础数据候选”指两端价格记录状态、观察行完整性及当前事件检查没有触发问题；不表示订单已成交、没有任何漏报公司行动，或标签已获准训练。所有训练批准标记仍为false。

剩余90,430条记录按预登记的优先级归为以下主要原因，每条只计一次：

| 主要原因 | 记录数 |
|---|---:|
| 计划退出跨到2024保留区间 | 17,667 |
| 进入日缺行 | 1 |
| 进入日停牌或开盘量价记录无效 | 1,505 |
| 退出日缺行 | 168 |
| 退出日停牌或开盘量价记录无效 | 4,377 |
| 期间已识别分红送转，权益处理待核验 | 61,708 |
| 配股保护区间重叠 | 439 |
| 参考价通用公式差异 | 3,415 |
| 特殊参考价/权益处理 | 24 |
| 单来源未独立核对的分红金额 | 1,126 |

此外保留全部可重叠的原因位，便于后续逐项处理。凡窗口跨出开发区间，缺行标记也可能来自主动不读取保留期价格，不能据此说供应商缺失行情。真实的范围内缺行须查看 `audits/label_schedule_dev_v1_validation.json` 中单独计算的范围内诊断。

分红等事件会使标签缺失呈现行业和事件依赖，因此覆盖率不能证明没有选择偏差。按年份、行业的覆盖表已经生成。后续需要扩展受支持权益类型并进行敏感性检查；不能只用较容易处理的样本完成原协议的全账户收益验收。

## 训练时点检查

计划退出日收盘只是标签最早可能可得的日期。真正准入还须等实际成交信息和所有必要的最终事件信息可得。

| 建模截面 | 已有资格信号记录 | 计划退出晚于训练截止日，须清除的记录 |
|---|---:|---:|
| 2020-12-31 | 1,620,364 | 16,300 |
| 2021-12-31 | 2,308,788 | 17,572 |
| 2022-12-31 | 3,023,277 | 17,774 |

三次截面分别涉及最后6个信号交易日。不能因为离线文件已经有下一年行情，就把这些结果提前放进训练。上述数量仍是日历成熟诊断，不是已经核实的训练标签数量。

2024年的价格及收益没有用于本轮统计。日历表可以为2023年末信号列出落在2024年的计划退出日期，但这些尾部记录保持未成熟，不补入保留期价格。

## 数据准入与下一项工作

未来公司行动或未来数据质量问题仅用于标签缺失诊断，不得成为t0筛股条件，也不得直接进入模型特征。原资格池标记和所有观察记录都保留。未知不填零，停牌与缺行分别处理，计划成交与实际成交分别处理。

下一项具体工作是实现用于标签核验的最小成交及单笔记账规则：普通买卖、无法成交、停牌、现金分红、股份到账和可售时点、实际费用/税款/容量。通过后生成受支持范围的收益值，回到第11步检查训练窗内的收益分布、异常和缺失偏差，再进入因子定义及筛选。第11步尚未被标记为全部完成。

当前定义与调度审计已完成；收益标签准入、最小执行审计、因子选择、模型及完整账户回测继续关闭。

## 文件入口

- `label_definition_v1.json`：在覆盖统计前登记的目标、权益、缺失及成熟口径。
- `audits/label_definition_v1_registration.json`：定义及原协议/输入清单哈希。
- `inputs_pre2025/label_schedule_dev_v1/`：六年逐日记录及覆盖表，仅调度与诊断，没有目标收益列。
- `audits/label_schedule_dev_v1.json`：本轮审计汇总。
- `audits/label_schedule_dev_v1_validation.json`：五间隔、登记日边界、停牌/缺行、训练截止及不输出收益的检查。
- `research_stage_gates_v2.json`：当前进度与关闭的门槛。
- `audits/data_revision_v5_registration.json`：本轮23个文件登记，前版24个文件核验未变。

实现入口为 `src/audit_label_schedule_v1.py` 与 `src/register_label_availability_milestone_v1.py`。输入快照拒绝覆盖，后续标签数值另建版本，不改写本轮调度审计。
