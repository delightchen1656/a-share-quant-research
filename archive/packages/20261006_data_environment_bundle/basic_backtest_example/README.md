# 最小本地回测与SuperMind对照版

这是教学和迁移验收示例，不属于项目正式策略，也没有替换五条正式主线。本地因子文件名为 `默认策略.py`，对应的可直接粘贴文件为 `默认SuperMind策略.py`。

## 完全相同的策略口径

- 股票：`600000.SH`；独立空仓账户；初始资金100,000元。
- 上一交易日前复权收盘价高于20日均线的101%时转为做多；低于均线的99%时转为空仓；两者之间保持上一信号。
- 信号只使用上一交易日及之前的数据，下一交易日开盘执行。
- 首次买入目标仓位95%；不做日内重复调仓。
- 本地版和SuperMind版使用相同的0.20%单边滑点、0.03%佣金和5元最低佣金。

## 本地端执行限制

本地版强制执行A股T+1、买入100股整手、现金不得为负、停牌/零成交量不成交、涨停不开买、跌停不开卖、每日成交量5%容量上限、佣金、过户费、卖出印花税，以及按持有期计算的现金红利差异化税。信号使用前复权数据，成交和资产记账使用原始价格；随包附带的BaoStock现金分红快照用于现金与红利税记账。

只有日线数据时，无法知道开盘盘口深度、排队顺序、逐笔成交、券商拒单、网络延迟和实际账户费率，因此任何本地回测都不能诚实地称为“完全等同真实成交”。本示例把法定和账户约束落到代码，并用保守的日成交量上限近似流动性；SuperMind最终成交、分红和税费以平台撮合为准。

## 运行本地版

先双击迁移包根目录的 `一键环境安装.bat`。以后直接双击 `一键本地回测.bat`，完成后会自动打开结果目录。

对应的手工命令为：

```powershell
..\quant_env\Scripts\python.exe .\basic_backtest_example\local_backtest.py
```

输出保存在 `basic_backtest_example/output/`：`summary.json`、逐日权益、成交记录和未成交原因。

验证交易限制：

```powershell
..\quant_env\Scripts\python.exe -m unittest discover .\basic_backtest_example -p "test_*.py" -v
```

## 运行SuperMind版

1. 打开 `默认SuperMind策略.py` 并复制全部内容。
2. 在SuperMind新建Python策略并粘贴。
3. 初始资金设为100,000元，频率选择“每日”，回测日期建议设为2020-01-02至2026-09-30。
4. 使用独立空仓回测账户运行。平台处理实际涨跌停、停牌、T+1、成交量限制、分红、送转、印花税和过户费。
5. 对比两端结果时先核对成交日期和方向，不要求收益数字逐分一致；BaoStock与SuperMind的数据源、复权、开盘撮合和费用实现可能不同。
