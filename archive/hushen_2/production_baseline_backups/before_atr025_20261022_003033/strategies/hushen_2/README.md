# 沪深2

本地晚间工作台位于 `tracker/`，桌面快捷方式为“沪深2 星轨”。操作流程见 `tracker/README.md`。原模型数值树已恢复并保存到 `model/`：三份模型在2,595,713条历史样本上的预测误差为0，重建后的3,549条历史信号完全一致。2026-10-20又用已提交的2026-10-19行情完成了行情到三只候选的端到端只读验证；证据见 `model/VERIFICATION.json` 和 `model/END_TO_END_VERIFICATION.json`。

当前唯一登记：冻结 `C04_NEW` 因子、5槽、10万元独立账户。

2026-10-20最新ATR选择：交易用ATR全期统一为`clip(SMA14(max(high-low,abs(high-preclose),abs(low-preclose)))/signal_close,0.015,0.05)`，不改模型特征与因子。所选固定撤销回测入口为`backtest/replay_selected_price_atr.py --start-year 2020/2025/2026`，六月增加`--june`（年份2020）。选用对比中`price`行：`results/holdout_restricted/uniform_atr_comparison/attempt_20261020_051840/COMPARISON.json`。下方及原results登记文件的旧混合ATR收益仍保留作历史记录，不能当作当前全期统一ATR收益。

软件新信号已经使用相同价格TR公式，无需改模型或覆盖冻结信号；既有已接受订单/持仓在明确清零或重新登记前不回写。历史所选固定撤销回测的到期尾盘退出与软件次日开盘手动退出仍不同；ATR选择并未消除此执行差异。注资可用资金调整记录，但会改变后续建议数量；当前权益快照未做外部资金流剔除，不能直接作为策略收益曲线。当前软件仅有成交/现金调整，不存在独立的送转持仓数量、成本及解禁日更正功能。

## 因子

- M内部权重：`[0.5, 0.5, 0.0]`
- T内部权重：`[0.5, 0.0, 0.5, 0.0]`
- H内部权重：`[0.25, 0.25, 0.5, 0.0]`
- 外层权重：`M=0.6, T=0.0, H=0.4`
- 每日最多3只信号。

## 执行

- 10万元，5槽；同股同时唯一。
- 信号后设置7个自然日条件买单，触及目标价成交；历史容量不超过当日成交量2%时假定可成交。
- 买入后设置4ATR止盈、1.5ATR止损，最长持有30个自然日。
- T+1可卖；同日止盈止损同时触发时止损优先；到期未触发则退出。
- 包含佣金、印花税、滑点、涨跌停/停牌、公司行动及退市处理。

## 文件

- `CURRENT_SELECTION.json`：唯一登记。
- `runtime/strategy.py`：冻结公式和执行常量；只调用同目录冻结构建器。
- `runtime/frozen_builder.py`：从登记前研究最小化抽取的因子合成、排名与每日前三选择，不读取归档。
- `runtime/EQUIVALENCE.json`：在完整2020—2024公共面板上与原构建器逐项一致的校验记录。
- `runtime/verify.py`：核对当前代码、结果、权益曲线和登记哈希，不读取归档。
- `backtest/compute_risk_metrics.py`：直接从冻结日权益曲线复算58个起点的收益、最大回撤和Sharpe。
- `results/PERFORMANCE_SUMMARY.csv`：保留的收益表。
- `results/RISK_SUMMARY.json`：2020年Q1全量起点至2026-10-19风险汇总。

本登记是查看2025—2026后作出的后验选择，不是新的盲测结论；不包含实盘下单授权。

下述 `run_broker_replay.py` 是此前扩大修改范围的独立对照版本，不是本次用户要求的最小改动版本。

2026-10-20按用户要求，后续国金挂单可执行口径使用 `backtest/run_broker_replay.py`；明确规则见 `backtest/BROKER_EXECUTION.json`。默认沿用此前选定的五档即时成交剩余撤销、固定股数、历史混合ATR、5槽、7/30自然日和持续接单。可选 `--start-group june2020/q1_2020/q1_2025/q1_2026`。例如：`quant_env/Scripts/python.exe -B strategies/hushen_2/backtest/run_broker_replay.py --start-group june2020`。

股数在晚间接受时固定，待买单预留资金；首次触发后的未成余量撤销，不把同一买单自动重试到第7日。卖出部分成交保留剩余股份，并假设晚间核对后重新挂单。资金不足拒单，不按未来成交价自动变更委托数量。实际止盈止损报价取到分。持续接收信号，期末持仓按市值计价，不保留原回测37日停单尾窗。

其中“首次触发后买入计划结束”是本回测的明确执行约定。截图只证明交易所子委托余量撤销，不能据此证明国金条件母单一定不会再次触发；该母单规则仍需核实，未核实前不能称作真实国金全流程复刻。

本地仅有日线，仍使用用户2%日成交量和固定滑点/费率假设，不能重建瞬时五档、排队或实际国金成交；同日双触先止损仅是保守日线约定。部分卖出按成交腿计数，不等于完整清仓次数。另三种市价方式未伪装成等价IOC，须有独立盘口/队列假设才能模拟。

`replay_original_q1.py`、旧收益表和旧权益曲线保留为历史复现对照，不作为国金可执行业绩。该修改不改生产软件、模型、真实账本或券商委托。
