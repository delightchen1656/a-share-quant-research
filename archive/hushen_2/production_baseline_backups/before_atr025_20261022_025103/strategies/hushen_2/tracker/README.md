## 晚间流程

2026-10-20最新用户确认：国金不能预约到期尾盘退出，改为原计划到期交易日收盘后仍有持仓时，在下一交易日开盘手动卖出。软件顶部独立“开盘手动卖出”栏高亮股票、剩余股数和日期，并区分下一交易日、今日及逾期；侧边待办可点击打开详情并进入实际卖出录入。按真实交易日历跳过休市日。仅查看/关闭提示不修改账本，部分成交继续提示剩余股份，全部卖出后移除。次日待处理提示不妨碍前晚完成核对，开盘后未回填则保留待办。用户撤回外部通知要求，因此不创建Codex提醒、操作系统通知或额外定时任务。

此处改变了实际到期退出时点。现存基线与固定股数回测仍为原到期日尾盘退出，不能视为手动次日开盘规则的收益；本次未重跑或覆盖历史收益表。止盈止损仍按原参数办理，并核对旧卖单与剩余数量。

后续回测对齐：`backtest/replay_original_q1.py --fixed-ioc`现默认使用软件的手动到期退出时点：原到期交易日保留盘中止盈止损，不再到期收盘强平；未退出则下一真实交易日以开盘价加原卖出滑点尝试退出，优先于该日后续盘中触价。停牌、股份锁定、一字跌停继续沿用原限制，未卖出时后续交易日开盘重试。只改这一退出时点，不改变原混合ATR、预算、固定股数、2%容量及资金复用；因此并非将软件所有执行差异同步到回测。历史结果保留；新输出另存`fixed_ioc_manual_expiry_open_*`。需要复现旧固定股数收盘退出结果时增加`--legacy-expiry-close`。本次已改代码和测试，尚未重跑全量收益表。

2026-10-20用户批准交易用ATR改为原后段回测口径：`clip(SMA14(max(high-low, abs(high-preclose), abs(low-preclose)))/close, 0.015, 0.05)`，读取与原回测相同的前复权行情序列。仅使用信号日及以前记录，信号日冻结，成交后不重算。选股模型的14项输入、权重和排序不变。已有挂单和持仓继续沿用账本中冻结的ATR，不回写；新口径信号使用独立带政策标识的缓存文件，旧原件保留。原历史收益表是混合ATR口径，不能直接视为修改后软件的收益。

1. 18:30后台读取已提交行情和交易日历；不会启动第二个行情下载进程。
2. 19:00后至下一交易日开盘前，先录入当天实际成交、撤单、资金变化，再完成账户核对。
3. 根据持仓状态处理必要卖单。买入次日起可卖；以信号日固定ATR、实际成交均价计算4ATR止盈和1.5ATR止损。
4. 有空槽且数据与模型就绪时，处理原始前三信号。接受表示你已在国金设置买单；拒绝无需原因。
5. 点击今晚操作完成。保护单、到期退出、残留卖单、账户核对和数据异常未处理时会阻止完成。

有效挂单和持仓合计最多5槽，同股合并占槽。未处理推荐跨日自动拒绝；已接受的国金订单不会被软件自动撤销。成交一律来自人工录入。

资金处理：未确认实际买入成交前，接受挂单仅占槽，不扣现金、不预留现金；录入部分成交时只扣实际成交金额与费用。现金卡片的“编辑”可直接输入现金余额（含当天卖出款，非账户总权益），保存为可冲正的现金差额记录，必须填写说明，不改已有挂单股数或持仓，不计入已实现交易盈亏；保存后需重新核对账户。编辑前先补录成交，避免之后重复扣款。软件余额不代表国金实际可用资金，券商可能冻结委托款。建议股数算法的可用资金上限与额外5元缓冲仍保留，本次不将这些其他差异同步到回测。

历史试验（后续已撤回，不是当前选择）：`replay_original_q1.py --fixed-ioc --filled-slots`显式采用`FILLED_SLOT_PROTOCOL.json`。信号日按总权益÷5÷挂单触发价向下取整100股（取消取整前滑点缓冲），股数固定；待成交买单不占槽、不预留资金，实际正股数成交才占一个槽。同股同时仅一单/持仓；仍只有冻结原前三信号，不增加排名。保留7自然日窗口；即使满仓也可生成后续待触发单，触发时才检查空槽和现金，失败即按IOC结束、不自动重挂。已售槽位及资金仍次日复用，部分成交占槽、零成交不占槽。
