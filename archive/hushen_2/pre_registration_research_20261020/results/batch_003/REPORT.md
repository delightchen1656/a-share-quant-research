# 沪深智能1 Batch 003：双基准参考与等步长测试

## 结论

本批次把现有「沪深筛选1」三模型分数、当前技术趋势分和「沪深1」四因子逻辑放入同一股票池，按预注册的等步长网格依次测试。共完成174次账户回放；只使用2024年及以前数据，未修改生产策略或创建真实订单。

## 三个选股分量

- `M`：沪深筛选1冻结模型 `utility/pen025/pen100` 的均分，在当日股票池内做百分位排名。
- `T`：`0.35×rank(120日动量) + 0.25×rank(收盘价/60日最高价-1) + 0.20×rank(20日动量) - 0.20×rank(60日波动)`。
- `H`：参考沪深1，`-0.35×rank(市值代理) - 0.20×rank(60日波动) + 0.25×rank(20日隔夜收益) - 0.20×rank(20日日内收益)`，再做5期平滑。市值代理采用`成交额/换手率`。

最终赢家均为：

`F = 0.25×rank(M) + 0.25×rank(T) + 0.50×rank(H)`

这里的H只是将沪深1公式移植到沪深智能1的合格池中，并非复刻沪深1原股票池、20交易日调仓或账户表现。

- 2020—2021与M分量三模型的训练期重叠；真正的跨时间观察仅为2022—2024，但这三年现在也已参与开发比较，不能再称盲测。
