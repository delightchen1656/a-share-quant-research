# 沪深智能1 Batch009：pre-2025 CAGR 与上证年化超额联合优化

## 结论

本批次严格使用 2024-12-31 及以前输入，固定 13 个 OLD/NEW 有限插值与模块桥接候选，先施加跨时间硬门槛，再在 8 个合格候选中按事前联合规则选出唯一冠军 `C05_M25`。没有看到结果后扩网格，也没有修改生产、当前生产登记或发送真实委托。

冠军只把 OLD 的 M 内部权重向 NEW 移动 25%，其余结构与 OLD 完全一致。筛选近似下 CAGR 为 30.0743%，同期上证价格指数 CAGR 为 1.9040%，按事前定义的年化超额（策略 CAGR 减指数 CAGR）为 28.1703%。原始 OHLC、完整公司行动与退市复审后的 CAGR 为 30.6107%，年化超额为 28.7067%。

OLD 自身的筛选 CAGR 更高（31.0574%），但其事前邻域包含 `C01_FULL25`；后者出现负年度收益并违反最差年度超额下限，因此 OLD 没有通过“候选及全部预定义相邻点均须通过”的邻域硬门槛。冠军不是简单的全样本最高 CAGR，而是通过全部门槛后的收益第一名。

## 事前协议与隔离

- 指令边界：`public-pre2025-v1`；最大信号日 2024-11-22，最大输入/执行日 2024-12-31。
- 候选：OLD、NEW、全结构 25%/50%/75% 线性插值，以及 OLD 基底上 M/T/H/outer 各 25%/50% 单模块桥接，共 13 个。
- 固定执行：10 万元、10 槽、每日最多 3 信号、买单 7 自然日、entry 0 ATR、take 4 ATR、stop 1.5 ATR、30 自然日、T+1、同日双触止损优先、2% 容量及原费率滑点。
- 硬门槛：五个年度逐年、五折年度留一、2020—2022/2023/2024 扩展时间、每候选 25 个共享 Q1 随机起点，以及事前参数邻域稳定性。
- 明确下限：每年收益 >0、每年信号至少 180、每年完成交易至少 150、最差年度超额不低于 -10%、年度平均超额 >0；每个留一年折和扩展窗口的策略几何年化与年化超额均 >0；随机起点每次至少 120 笔完成交易、逐年起点均值的最小值 >0、正收益比例至少 80%、终态为空。
- 联合排名：仅在全部硬门槛合格者中，`0.5 × CAGR百分位排名 + 0.5 × 年化超额百分位排名`。所有候选共享同一指数区间，二者排序数学上相同；仍同时保留以明确双目标，随后以年度平均超额、最差年度超额、随机起点最差年度均值和候选编号破同分。

## 冠军精确公式

先在每个交易日做截面百分位并中心化到 `rank_pct - 0.5`：

- `M = rank_day(0.3125×utility + 0.6875×pen025 + 0×pen100) - 0.5`
- `T = rank_day(0.50×mom120_pos + 0.25×high60_pos + 0.25×mom20_pos + 0×vol60_neg) - 0.5`
- H 的原始横截面组合为 `0.25×size_neg + 0.25×vol60_neg + 0.25×overnight_pos + 0.25×intraday_neg`；按股票做 5 日滚动均值（至少 3 日），再做当日截面百分位中心化得到 `H`。
- 最终 `score = 0.30×M + 0.30×T + 0.40×H`；每日按 score 降序、symbol 升序稳定排序，取最多 3 只。

因此冠军相对 OLD 的唯一结构变化是 M 从 `[0.25, 0.75, 0]` 改为 `[0.3125, 0.6875, 0]`；T、H、外层及全部交易执行均不变。
