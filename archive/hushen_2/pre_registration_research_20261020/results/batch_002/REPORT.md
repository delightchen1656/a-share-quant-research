# 沪深智能1 Batch 002 研究报告

## 结论

按预注册的首要目标「2020—2024连续账户CAGR最大」，30自然日分支的唯一第一名是 `model_stable_75__entry0.25atr__wide__30cal`。原始价格与公司行动审计后CAGR为 **6.98%**，10万元变为 **140,117.33元**。

但它不应被表述为已证明的跨时间通用策略：三份冻结模型的训练年为2018—2021，2020—2021与拟合期重叠；2022—2024累计收益为 **-8.71%**，年化约 **-2.99%**。因此当前只登记为研究结果，不替换任何生产策略。

7自然日分支的独立第一名为 `model_mean__entry0.25atr__balanced__7cal`：完整期CAGR **2.60%**，2022—2024累计 **5.45%**、年化约 **1.79%**，跨时间稳定性好于30日主候选，但收益更低。

## 因子与买卖点

### 30日CAGR第一名

1. `M = mean(utility, pen025, pen100)`，三个模型为「沪深筛选1」现有冻结模型，本研究没有重训。
2. `T = 0.35*rank(mom120) + 0.25*rank(close/high60-1) + 0.20*rank(mom20) - 0.20*rank(vol60)`。
3. 最终分数 `F = 0.75*rank(M) + 0.25*rank(T)`，每日最多2只。
4. `A = clip(ATR14/close, 1.5%, 5%)`。买点为信号收盘价 `*(1-0.25A)`，条件单有效7个自然日。
5. 实际成交后，止盈价为成交价 `*(1+2.5A)`，止损价为成交价 `*(1-1.5A)`，最长30个自然日。

### 7日分支第一名

1. 使用 `M`原始均分，要求 `M>=0.10`，每日最多2只。
2. 买点同上：信号收盘价 `*(1-0.25A)`。
3. 止盈为成交价 `*(1+2.0A)`，止损为成交价 `*(1-1.25A)`，最长7个自然日。

## 审计边界

- 只读取2024-12-31及以前的行情与公司行动，未访问2025年以后结果。
- 五档历史委托簿不可得；按用户授权，委托量不超过当日成交量2%时默认整笔成交，另计单边0.2%滑点。
- 30日分支处理35次公司行动：22次来自已有Baostock响应缓存，13次来自Eastmoney公开分红表。7日分支的实际持仓没有遇到公司行动。
- Eastmoney补充表不单列现金支付日和红股上市日，审计以除权日代替；这是保留限制，不宣称与券商成交完全一致。
- 两个分支各有4次止损触发遇一字跌停，当日不成交，后续可交易时重试。真实国金条件单触发后是否自动重发仍需券商端确认。
- 这些是历史开发结果，不是真正未见盲测，也不代表未来收益。
