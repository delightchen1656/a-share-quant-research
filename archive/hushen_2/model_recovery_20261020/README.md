# 沪深2模型行为重构

最新状态：已从Git不可达历史平台脚本恢复原数值树，三模型259万条原预测及3,549条最终信号完全一致。恢复入口为 `recover_embedded.py`，结果为 `original_numeric_v1/`，详见 `STATUS.md`。下方描述仅适用于较早的近似重构方案 `behavioral_v1/`，不再作为优先恢复方案。

本目录与正式 `model/` 隔离。`reconstruct.py` 使用保留的原模型预测作为教师，重建能接收14项特征的两个LightGBM回归模型，不依赖未来行情收益标签。

## 固定方案

- 训练：2020—2021年，保持训练信息截止于2021年。
- 时序评价：2022、2023、2024年，仅评价，不据结果调参。
- 不读取2025年以后行情、预测或收益；这些年份的既知业绩不作为本次输入。
- 两个模型均固定500轮、63叶、学习率0.04；其余参数及输入SHA256在运行前写入 `behavioral_v1/PROTOCOL.json`。
- 与原沪深2使用同一因子合成器，报告分数误差、每日排序相关、每日前三重合率。
- 生成模型重新加载后预测，检查特征顺序、非有限值、日期边界、重复键和输入连接完整性。

运行：仓库根目录执行 `quant_env/Scripts/python.exe -B strategies/hushen_2/recovery/reconstruct.py`。

## 不可混淆的边界

这不是原文件的字节恢复，也不是原训练标签下的确定性重训。教师仅保留有限样本的输出，无法据此唯一确定原树结构。即使排序和选股相近，也不能保证未来一致。

生成文件只保存在 `behavioral_v1/`，不复制到生产 `model/`，不修改 `CURRENT_SELECTION.json`，不启用每日真实推荐、不连接券商。原沪深2历史收益不能标成重构模型收益；需另做相同账户规则的回放及风险评估后，才讨论是否启用。

2026-10-25归档精简后只保留可复现来源：`recover_embedded.py`、`reconstruct.py`、`test_reconstruction.py`、`behavioral_v1/PROTOCOL.json`，以及 `original_numeric_v1/` 中的原数值树、平台源脚本、等价模型和核验证据。早期近似模型、教师信号、诊断CSV和Git搜索过渡脚本已物理删除；当前生产模型仍以 `strategies/hushen_2/model/` 和根目录独立软件的模型清单为准。

本任务的操作者已接触过2025年后历史结果；这里只能声明本次脚本输入截止2024年，不能宣称人员层面的全新盲测隔离。
