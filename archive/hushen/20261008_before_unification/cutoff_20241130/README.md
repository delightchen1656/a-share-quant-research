# 沪深1：截止2024-11-30的参数重估

完成日期：2026-10-04。平台入口为 `../supermind_mainboard_baseline_1_cutoff_20241130.py`；原R08入口保持冻结，没有覆盖。

## 冻结协议

- 可用观测严格早于2024-11-30，实际最新交易日为2024-11-29；训练只读取本目录隔离快照及同截止日的中证500，不读取最新行情、当前证券状态、未来退市信息或行业映射。
- R08没有机器学习模型。本次只在9组有限网格中重估历史价格调整代理、长期风险调整动量、低波动三项排名权重。
- 目标仍为12只、95%仓位、候选60、缓冲24、奇数月调仓；执行和费用逻辑不变。
- 监督目标是信号日后40个交易日的累计价格调整收益代理，完整标签窗口必须在截止日前结束；停止报价者保守记为-100%。因子IC不是组合收益。
- 开发段为2020—2022，跨开发/验证边界标签剔除；验证段为2023—2024-11-29，只检验开发段已选版本，不据验证重新选权重。
- 历史框架曾接触后续数据，供应商记录也不是2024年当时保存的原始快照，因此不能宣称完全独立样本外。
