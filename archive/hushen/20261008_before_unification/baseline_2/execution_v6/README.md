# 沪深基准2：平台执行基础版 V6

用户于2026-10-08授权以本轮上传的 fast-v5 为底稿，解决模拟订单未完成、报价陈旧、重复回报及价格/税费口径问题，提供新平台基础版与对应本地回测版。不是重新训练或按收益调参。旧正式入口和源版本继续冻结，V6是基准2的新平台执行基础文件，尚未在SuperMind服务器验证。

## 使用文件

- 平台：`supermind_baseline2_execution_v6_minute.py`，整份复制到SuperMind。设置 **分钟频率、100000元、独立空仓起始账户**。不能选每日频率；代码会明确报错，防止悄悄只执行一次。新建回测后再新建模拟，不把已有v4/v5模拟账户状态直接混入。
- 本地：`local_backtest.py`，直接加载上述平台策略的执行函数，使用独立异步账户/撮合器。不复制另一套选股或订单状态机。
- 原始上传：`source_v5.py`，SHA256 `15f969943623c5f51febdad9f96c6b7834b7aa7c9ea3de4b764efba8fe2866f9`，与原正式基准2相同，不是上一轮分析的v4或严格重训版。
- 构建：`build.py` + `execution_functions.py`，生成可独立上传的单文件；`verify.py` 为执行回归测试。

## 保留与变更

因子、过滤、历史读取及固定日历相位函数与上传v5 AST逐项一致：市值/波动/隔夜/日内系数 -0.35/-0.20/+0.25/-0.20；60/20日窗口；5日平滑至少3日；5只目标、98%仓位、保留缓冲1.5、20交易日调仓。首次建仓额外触发。没有改成自然月、周调仓或严格重训权重。

执行明确改为分钟：

1. 09:31起使用已完成分钟的close报价；调仓预算也按首次执行时的分钟价估值，不再冒充精确开盘成交。平台Bar.datetime与策略时间差超过90秒或指向未来时不下单。
2. 买入限价参考分钟价上浮0.1%、向上取整到分；卖出下浮0.1%、向下取整。限价受当日涨跌停及每股当日首次报价±1%的追价边界约束。超过边界不追单。上述参数是固定工程默认值，未经收益选优，不保证成交。
3. 每只股票每日至多6次提交，间隔至少5分钟。旧单存续5分钟发起撤单，必须等查询/回报确认终态，下个分钟才能按最新持仓重算余量并重报。部分成交、撤单竞态均以账户和订单成交量为准。
4. 10:00起不再提交，撤销本策略仍存续的委托；若撤单未确认，后续分钟继续核查，最多每5分钟再次发起撤单直到14:57，避免撤单风暴。收盘只报告残差，不调用全账户撤单。
5. 当日成交量累计不超过前20日均量0.5%，每单最多100万股；平台分钟成交比例25%；买入100股整手，卖出遵守可卖数量/T+1。卖出资金真正到账后才可买，未完成卖出可能使实际持股数暂时超过目标5只。
6. 未完成目标沿用原版：后续交易日继续补，下一次20交易日调仓替换。没有引入隔夜挂单、三日目标过期或强制清仓。分钟重报会增加委托数及可能的最低佣金。
7. 关闭平台额外滑点（PriceSlippage(0)），避免限价之外再人为加一层成交记账价差；成交回报仍会检查买价超限/卖价低于限价。平台若忽略设置，会输出LIMIT_BREACH，不能宣称已经解决平台内部撮合问题。
8. 订单以ID/状态/成交量去重，成交以exec_id去重；旧回报不得倒退终态或已成交数量。只能控制策略自身打印，平台UI或日志传输层重复无法由此保证消除。盘前打印UTC墙钟、策略时间和耗时，帮助区分计算耗时与调度/显示延迟。

## 费用边界

平台佣金设置为万三、最低5元。官方公开API未核实到可独立改写股票印花税/过户费的接口；不杜撰set_tax，也不更改平台现金或虚构收益曲线。

每次成交核验tax字段与交易日期对应的预期印花税，不符输出FEE_MISMATCH。该告警是暴露问题，不是把平台税费修正成功。用户日志的0.1%税项仍须平台确认；收到新版实际回报后才能验证平台执行/费用修复效果。

本地账户：佣金万三最低5元，按订单累计成交额计最低佣金，部分成交不重复收5元；撤单重报是新订单。过户费2022-04-29前万0.2、之后万0.1；卖出印花税2023-08-28前0.1%、之后0.05%；FIFO分红税及送转股沿用原审计账本。本地费率是用户接受的研究口径，不是已经核验的国金账户合同。

## 本地运行

在仓库根目录运行：

```powershell
.\quant_env\Scripts\python.exe strategies/hushen/baseline_2/execution_v6/verify.py
.\quant_env\Scripts\python.exe strategies/hushen/baseline_2/execution_v6/local_backtest.py --mode daily-proxy
.\quant_env\Scripts\python.exe strategies/hushen/baseline_2/execution_v6/local_backtest.py --mode minute --minutes C:\data\minute_bars.parquet
```

默认区间2020-01-02至2026-09-30，独立10万元。初始日期顺延交易日，所选首次交易日必须有冻结排名，否则明确报缺少排名，不能擅自替换信号。结束日期超出已验证本地行情时拒绝执行。排名来自原版冻结结果，运行前检查全部原始行情及日历哈希；历史代码、数据、公司行动缓存依赖保留在当前仓库，不是脱离仓库的单文件回测器。

分钟输入为不复权价、上海时区无时区标记、时间戳代表已完成分钟。字段：datetime, symbol, open, high, low, close, volume（股）, high_limit, low_limit, is_st（0/1）, is_paused（0/1）。每日09:31至10:01必须完整覆盖当日候选/目标/持仓，停牌要保留零量记录；缺失、重复、无效OHLC直接报错。不可将日线展开为分钟冒充历史行情。

分钟回放使用“本分钟收盘决策、下一分钟才可能成交”，先撮合再处理该分钟回调；限价不得被滑点穿透。开盘不能成交时只在价格严格穿过限价后按限价近似撮合，仅碰价不假设排队成功，分钟量25%约束可造成部分成交。固定0.1%价格冲击可用--impact调整，但不得依收益搜索；真实队列、盘口与网络延迟仍无法由OHLC复原。收盘采用本地原始日线估值；公司行动缺项保留为issues，不伪称已全部覆盖。

**daily-proxy不是分钟回测成绩**：本地当前只找到日线。该模式用两个明确标记的合成开盘事件测试整段账户路径，按开盘价成交（实际价格冲击为零）、日成交量近似容量，异步卖出到账可能将部分买入延至次日，不模拟盘中撤改单。它用于日线粗对照/账本运行检查，不能证明V6的收益、回撤或成交改善，也不是收益上下界。不要把它与旧版指标直接作优劣排名。

输出在results_daily_proxy或results_minute：逐日资产、逐笔成交、订单状态、费用、公司行动问题和来源哈希。年化按自然日含首尾，Sharpe用日收益样本标准差、252日、无风险利率0；期末不强制平仓，不扣未来退出成本。
