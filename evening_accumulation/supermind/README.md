# SuperMind 科创板 r09 模拟盘

1. 最简单：打开 `supermind_star_r09_single.py`，复制全部内容，替换SuperMind默认股票策略模板。该文件已经内嵌模型，不需要上传JSON。
2. 或在SuperMind项目中同时上传 `supermind_star_r09.py` 与 `star_r09_model.json`。
3. 创建“股票策略”，运行频率必须选择 **1分钟**；日频无法盘中执行6%/20%/30%风控。
4. 初始资金建议100万元，回测区间可设2025-01-01至2026-07-31，复权方式由代码中的历史查询指定为动态前复权。
5. 先编译、回测；确认无API版本差异后，从回测详情页开启模拟交易。

平台策略每天开盘前分批获取科创板过去121根日线，计算与本地r09相同的18项特征并用便携JSON树模型评分；概率至少0.62时，每日最多保留8只候选，次日开盘每只目标仓位10%，最多12只。分钟级检查6%止损、20%减半、30%清仓和60日退出。

注意：SuperMind使用动态前复权，本地训练来自BaoStock前复权；两者复权细节、停牌填充、滑点撮合和字段精度可能不同，因此平台回测不会与本地结果逐笔完全一致。若平台策略编辑器不能读取同目录JSON，请在研究环境将两个文件放在同一工作目录，或联系平台确认策略附件路径。

## 事件识别标准档

使用 `supermind_event_standard_single.py`，整文件复制进SuperMind策略编辑器，不需要上传模型附件。当前基准为优化30日版：概率阈值0.689688、每日最多8个候选、最多14只持仓；-7%止损、+24%减半、+34%清仓、30交易日到期。回测频率必须选择1分钟。

速度版把每日历史查询由7批降为3批，60日特征改为NumPy直接窗口计算，并对全股票池批量执行300棵树。本地等量热点基准预测完全一致，估算每日计算热点加速约11.56倍；平台总回测速度仍取决于SuperMind数据服务负载。

`supermind_event_standard.py` 与 `event_standard_model.json` 是便于审计的分离版本；实际平台运行优先使用single单文件版。该文件不导入`os`，也不调用`open()`，符合此前已验证的平台沙箱限制。

当前正式文件名为 `supermind_event_baseline30_strict_single.py`。它与 `supermind_event_standard_single.py` 内容一致，但独立命名用于防止误传旧版。严格交易包括T+1状态检查；涨跌停不可成交、部分成交、税费和可卖数量最终由SuperMind撮合引擎与账户规则执行。

## 实盘约束 V2

`supermind_event_baseline30_live_constraints_v2_single.py` 是不覆盖旧基准的实盘约束版。它增加成交分钟停牌/零成交检查、涨停等待开板后才买、跌停期间延后卖出、200股与可用现金预检、待成交买单占用持仓槽位、部分成交T+1登记，以及每日 `EXECUTION_AUDIT` 买卖额和换手日志。

默认成本场景为 `neutral`，约单边0.20%不利滑点，另计万三佣金和最低5元。可把文件顶部 `COST_SCENARIO` 改为 `optimistic`、`stress` 或 `severe`，分别测试约单边0.10%、0.30%和0.50%滑点。

V2仍使用固定的2026-07-31科创板存续股票清单，这是此前“不要历史退市股票”的数据口径，会产生历史幸存者偏差。若要消除此偏差，必须重新下载逐日可交易股票状态并重新训练模型，不能只修改撮合代码解决。

## 实盘规范 V3

`supermind_event_baseline30_live_realistic_v3_single.py` 是当前推荐的模拟盘/实盘验证版本。它不依赖 `on_order` 回调维护核心持仓状态，而是在每一分钟从账户实际持仓主动对账：新持仓建立本轮成本，实际减仓确认半仓标记，持仓消失则清除旧状态。因此日频回测曾出现的“重新买入沿用第一次入场价”不会进入模拟盘或实盘。

V3还在策略层明确阻止不足200股的科创板半仓减持。运行频率必须选择1分钟；V2和日频兼容版仅保留作历史对照，不再作为实盘候选。

对应本地评估文件为项目根目录下的 `backtest_live_realistic_daily.py`，结果写入 `outputs/live_realistic_daily/`。本地版本采用T日收盘信号、T+1开盘成交以及独立交易状态，绝不模拟平台回调缺失问题。

## 市场风控 V4

`supermind_event_risk_control_v4_single.py` 是“暴涨前形态识别＋动态风控”的单文件版本，已经同时内嵌选股模型和市场风控模型，不需要上传JSON。运行频率必须选择1分钟。

盘前使用已完成的前一交易日日线，统计固定科创板股票池的等权收益、上涨家数、均线上方比例、创新低比例、横截面波动以及科创50/等权背离，再输出90%、75%、50%、20%四档总仓位上限。风险升高时先卖出模型概率最低的持仓；跌停或T+1不可卖时继续等待合法成交，不假设强制成交。核心持仓状态继续以账户实际持仓主动对账，不依赖`on_order`回调。

本地2023-01-01至2026-07-31、1000万元对比中，原策略期末3207.93万元、最大回撤39.33%；风控版期末3218.34万元、最大回撤18.71%。该结果仍需在SuperMind分钟环境验证，不能直接视为实盘收益承诺。

## 确认式风控 V5

`supermind_event_risk_control_v5_confirmed_single.py` 用于修正V4长期低仓位问题：正常状态允许100%仓位；初级预警只停止新增，不强卖；主要风险连续两天确认后降至60%；极端风险降至20%；风险解除后分三天恢复。组合从历史高点回撤10%时仓位硬上限50%，回撤15%时上限20%，连续五个低风险日后逐级解除。

本地2023-01-01至2026-07-31、1000万元结果：期末2397.06万元，年化27.72%，最大回撤8.05%；2026年1至7月-3.90%，7月-0.96%。这是更强调回撤控制的版本，收益低于原策略，不保证SuperMind平台完全复制本地结果，必须使用1分钟频率重新回测。
