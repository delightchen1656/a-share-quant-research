# SuperMind平台版本说明

上传文件：`supermind_strategy3_bear_downside_v1_single.py`。这是单文件版本，不需要上传模型附件。

平台设置：

- 频率：每日；
- 基准：科创50 `000688.SH`；
- 推荐首次回测区间：2020-01-01至2026-07-31；
- 初始资金：先用100万元复核，再做1000万元容量压力测试；
- 模型有效期：2026-09-30。进入2026Q4前必须重新训练并导出季度熊市模型。

代码内嵌：

1. 原异常拉升识别模型；
2. 基准1-2先止损概率模型；
3. 2021Q1至2026Q3共23个季度走步熊市模型。

策略变化：先止损概率高于0.50的候选不买；候选按上涨概率减去0.22倍先止损概率排序；再扣除0.10倍当前组合下行相关性。熊市概率达到40%/55%/70%时，新仓目标从10%调整为9%/7.5%/5.5%。不强制卖出已有仓位。

平台实际撮合可能因行情接口、停牌、涨跌停、最小200股、部分成交及订单状态回调与本地结果不同。第一次平台回测后应导出交易明细再做对齐，不能把本地结果直接称为平台结果。
