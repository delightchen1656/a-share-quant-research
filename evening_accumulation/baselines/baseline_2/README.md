# 基准1-2：止损过滤

> 正式名称：基准1-2止损过滤。旧称“策略2低风控版本1”。状态：2026-08-23正式冻结。后续研究不得覆盖本目录中的模型、参数和结果。

原内部编号为Baseline2。基于冻结的Baseline1，只增加一个独立风险模型，判断候选股票未来22个交易日内是否可能先触发-7%止损而非+24%止盈。

正式规则与完整实验结论见 `research/REPORT.md`。Baseline2保持Baseline1所有交易参数，只做以下两项变化：

1. 过滤 `stop_probability > 0.50` 的候选；
2. 候选排序改为 `probability - 0.22 * stop_probability`。

全周期本地结果（2020-01-01至2026-07-31）：年化61.15%，最大回撤-31.73%。
样本外（2025-01-01至2026-07-31）：年化29.63%，最大回撤-30.74%。

本目录是本地研究基线。SuperMind版本需在平台可用API约束下另行转换并复核成交一致性。
