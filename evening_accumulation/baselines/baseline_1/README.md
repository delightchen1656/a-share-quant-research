- 模型阈值：0.689688。

- 单票目标仓位：账户资产的10%。
- 止损：-7%。
- +24%卖出一半，+34%全部卖出。
- 最长持有：30日。
- SuperMind运行频率：每日，约09:31执行。
- 中性滑点：双边0.4%，约单边0.2%。
- 佣金：万分之三，最低5元；包含印花税、过户费、科创板200股约束及涨跌停/停牌检查。
