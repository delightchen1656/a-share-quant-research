# 沪深2 K线练习室

## 独立运行包

本目录已经自包含练习程序、冻结执行引擎、历史信号、结算输入和2013—2026历史行情快照，不再读取 `strategies/hushen_2/` 的研究结果，也不再从 `archive/` 导入源码。`frozen_inputs/` 和 `runtime/` 是练习程序的运行依赖，不是可清理缓存。

- `runtime/`：冻结IOC执行适配器和原研究核心源码副本。
- `frozen_inputs/cases/`：ATR≥2.5%历史题目、结算输入及独立核验。
- `frozen_inputs/market/`：练习专用历史raw/qfq行情快照。
- `verify_package.py`：只读核验代码、信号和行情快照哈希。

运行前可执行：`quant_env/Scripts/python.exe -B 沪深2_K线练习/verify_package.py`。

## 时序边界（重要）

这是后来冻结的模型与规则对历史行情的回溯练习，不是逐年滚动训练的严格样本外测试。恢复记录确认原模型训练年份为2018—2021；因子与规则在2020—2024期间开发筛选，生产版本选择又查看过2025年后结果。较早年份不能称为当时可得预测，2025年后也不能再称新盲测。固定快照的前复权价格与历史股票池未在本游戏中重新完成逐日可得版本审计，不能据此保证整套研究没有未来信息影响。作答前隐藏未来OHLC、答案与实际成交，仅证明界面防剧透，不替代训练/选择时序审计。

练习净值纵轴动态调整，固定五条等距线，刻度按1.0+k×0.2排列，跨度较大时步长可为0.4、0.6等0.2的整数倍；实际净值不取整。

双击 `启动练习.pyw`，或访问本机 `http://127.0.0.1:18763`。程序在根目录独立运行，所有记录仅写本目录data，不连接国金、不改变生产策略和账户。

采用仅ATR≥2.5%版冻结信号。题目来自2015至2026-10-22的已核验历史快照；抽到的信号用原固定IOC引擎单独结算，尚未完成、停牌未退出、公司行动覆盖不全的信号排除。不是P12，不重新训练，不把抽题结果作为新盲测。

功能：

- 猜结局：买入失败、止盈、止损、到期平仓；按实际结局统计猜对/已答题。未答题自动续做，刷新不丢题。
- 买入或跳过：初始净值1；买入按扣费单笔收益复利，跳过不变。显示最近10/50/100次及全部操作。不代表五槽连续策略收益。
- 信号日前一年日K/周K、真实股数成交量、红涨绿跌、十字光标、拖动、滚轮、按钮及键盘缩放（+/-，左右平移，0还原）、双击还原。
- 横轴按交易日序号等距排列，周末与休市日不占位置；周线按交易周等距。揭晓后完整展示成交后30自然日内的全部可用交易日K线，提前止盈止损不截断，框外涨跌也照常显示；超出快照截止日的行情不虚构。
- 作答前服务端不返回未来K线、实际成交、答案。周K仅聚合当前可见历史，不混入未来同周数据。
- 作答前隐藏当前名称，避免ST、退市及更名提示历史结局；作答后名称来自当前元数据，不冒充当时名称。
- 虚线矩形为入场参考、4ATR止盈、1.5ATR止损及30自然日边界。作答前按触发价含0.2%滑点及下一交易日成交预估，揭晓后校准实际成交。前复权图缩放至信号日原始价格单位，不能混淆图表价与原始成交价。

执行口径明确沿用历史基线：单题10万现金、5槽预算中的一个槽、固定股数、7日买单、30自然日持有、T+1、同日双触止损优先、2%日成交量与原费用滑点、公司行动、到期日尾盘退出。与跟踪软件次日开盘手动到期退出仍有已知差异。本游戏不是实盘或盘口回放。

启动：`quant_env/Scripts/python.exe -B 沪深2_K线练习/app.py`。
