# D11提速版：截止2024-11-30的参数重估

生成日期：2026-10-04。平台入口为 `../supermind_test2_D11_fast_cutoff_20241130.py`；D11原版和普通提速版均未覆盖。

## 冻结协议与策略

- 复用相邻 `cutoff_20241130/snapshot/` 的隔离原始价并逐文件校验哈希；最大观测日2024-11-29，最晚20日监督标签为2024-11-07。
- 保留5日平滑、20交易日调仓、5只股票、98%仓位、持仓缓冲、费用和每日频率，只重估四因子权重。
- 9组配置由小市值负权重0.30/0.35/0.40、波动率负权重0.15/0.20/0.25、隔夜收益正权重固定0.25，以及剩余日内收益负权重组成。
- 开发段2020—2022按平均截面Spearman IC选型；2023年至截止日前只验证锁定版本，不据验证重选。
- 提速逻辑保持：调仓日计算全市场排名，非调仓日只维护持仓/目标股票状态；首日加载不保证加速。
