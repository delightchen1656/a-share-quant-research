# D11控制变量研究

用户授权：每类参数20组本地回测，控制其他参数，最后综合。独立目录，不覆盖原D11、严格重训版、沪深1或科创策略。

## 事前协议

`protocol.json`登记8类×20组：老持仓保留范围、调仓间隔、得分平滑、初始只数、几何扩容和降档缓冲、四因子权重、因子观察窗口、股票池过滤。只数2—21；扩容最多max(15,初始只数)。每类只改变自己的参数块，块内多个参数可有组合，不把它称为每个标量独立因果实验。

2018预热；2019—2022开发；各类最多3个候选加原版进入2023选择；20个事前登记的综合子集再次开发和选择。2024-01-01—11-29只确认，11-30—12-31隔离，2025—2026-09-30只评价冻结结果。后段不反馈选择。原框架曾暴露后续历史，本轮不宣称真正未见的前瞻盲测。

开发至少40次成交、平均仓位15%、回撤不超过同期原版2个百分点；2023至少10次成交，其余相同。有效组按扣费年化、夏普、较低回撤、编号排序；无改善可回退原版。公司行动/除权参考价异常的账本不参加选优，原始结果和异常均保留，不臆造调整数据。

综合模板重合时复用完全相同配置的账户结果，报告模板数与唯一配置数，不重复计算充数。夏普使用日简单收益、样本标准差、252日、无风险利率0，包含首日相对初始现金收益。

## 运行与产物

Python：根目录`quant_env/Scripts/python.exe`。

顺序运行`pipeline.py group_train`、`group_select`、`combined_train`、`combined_select`，然后`confirmation`、`heldout`。`frozen.json`创建后禁止训练/选择。`verify.py features`核对原导出函数和向量化信号；`verify.py control`核对既有2020—2022原版逐日净值；`verify.py`审计最终结果；`report.py`生成图表和HTML。

`training/selection/confirmation/heldout`各目录有价格输入哈希、参数化排名、逐配置净值、交易与调仓记录。`additional_actions.json`为按实际持有股票补充的公司行动响应，作为研究数据保留。

共用原D11交易函数和既有现金账本，执行适配器仅将固定20日判断参数化。使用日线开盘撮合近似，佣金万三最低5元、历史税费、T+1、整手、资金与成交限制不优化。平台真实订单/滑点、历史股票池完整性、供应商公司行动质量仍是局限；未生成新SuperMind入口，不实盘交易。

## 准备过程记录

- 协议首次生成的内部检查发现一个综合子集重复，在写出协议及读取绩效前修正；未触发任何候选试验。
- 160个开发配置有23个出现公司行动/除权参考价异常，按数据有效性门槛剔除出选优；并非全部160个都是数据无异常的有效绩效。
- 原版2020—2022逐日净值对照通过，5个独立原函数特征配置排序对照通过。

## 完成结果（2026-10-06）

160个控制变量配置和20个综合模板已完成；综合模板形成10个唯一配置。含独立分段，保存191次唯一账户回放，17项最终校验通过。综合候选仍是单类赢家windows_17：波动窗口120日、隔夜/日内10日，其余原版参数不变；机械叠加各类赢家没有更好。

候选2023选择段年化41.97%、回撤12.44%、Sharpe1.849；2024确认截至11月29日年化7.83%、回撤42.23%、Sharpe0.398，未通过准入。2025—2026-09-30隔离历史测试年化30.63%、回撤16.91%、Sharpe1.276；同段原版39.03%/19.43%/1.519。不据后段换参数或改选其他组，不晋升、不覆盖原版。

完整表和图：`report.html`；机器可读汇总：`summary.json`；异常清单：`data_quality_exclusions.json`；冻结记录：`frozen.json`。
