# 沪深1独立本地模拟

2026-10-17起账，10万元现金、空仓。每天北京时间18:30由本对话自动任务1-18-30维护。首次成交不得早于2026-10-18，且必须是核实交易日；2026-10-18是周日，不生成周日成交。

运行：quant_env/Scripts/python.exe -B strategies/hushen/tracking/run.py。

原D7f固定5只、98%、20交易日相位，第一次可交易日建仓。18:30是收盘后核对与模拟记账时间，不是18:30下单：使用此前冻结信号与交易日开盘、日线范围及容量约束近似撮合。目标股数在开盘时确定，盘后保存的是排名，不假称已知未来开盘股数。没有券商连接。

config.json为账户与策略指纹；tracker.json为状态；signals/保存不可回改的评分日信号及输入哈希；equity.parquet为连续净值；ledger_inputs/是本账户复现输入，不可普通清理。daily_report.md和daily_report.json保存最新交易日的账户、持仓与当日成交简表；自动任务在每个核实交易日运行后发送该表，休市日不发送。日线无法还原盘口排队，资金撮合为本地近似。

先检查18:00行情任务是否完成提交、数据审计/refresh及更新进程；不能读混合输入，不另开并行更新。每次从冻结信号重建资金路径，已有成交前缀须完全一致，否则停止。公司行动沿用已审计账本与真实响应，缺漏必须核查。缺少过去信号不事后回填；策略哈希变化须人工审查而非自动接受。

初始化核验发现601059.SH没有截至2026-10-16的最新日线。2026-10-18已核实：该股连续停牌，交易所决定2026-10-19终止上市且不进入退市整理期；供应商最后一行及10月16日证券主表均为非交易状态。程序保留其历史池成员身份、不提前剔除、不填造行情；无当日完成行情时自然不可选。证据见input_audit_20261018.json。
