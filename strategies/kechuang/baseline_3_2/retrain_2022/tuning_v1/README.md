## 搜索协议

1. 只读取既有2022截止物理快照拟合上涨模型；所有20日标签完整结束于2022年内。先止损模型固定沿用上轮仅拟合2020—2022的7叶模型，没有重新拟合或查看未来再改模型。
2. 在运行前写入protocol.json：上涨模型6个正则化配置，各搭配0.55/0.65/0.75门槛，共18组新候选；另有原重训版对照，共19组。不是无限网格搜索。
3. 全部使用原18特征、balanced类别权重、学习率0.04、固定随机种子、禁用随机早停。退出、持股数、容量及成本规则不变；先止损门槛固定0.35。
4. 仅按2023年选择：`年化收益 - 0.5×最大回撤幅度 + 0.25×最差季度收益`；要求至少40次成交、平均仓位至少15%。此评分是开发排序指标，不是通用收益保证。
5. 晋升开发门槛另要求全年盈利、至少两个季度盈利且评分优于对照。实际18组新候选2023年全都亏损，因此无一通过这一门槛。
6. 将相对最优候选写入frozen.json，冻结模型/平台文件哈希，然后评价2024和2025—2026-09-30，仅作诊断，不反向选择或追加候选。源码存在冻结文件时拒绝再次选参。
