# 科创3-2：1000组预注册参数搜索

完成日期：2026-10-04。本轮运行1000个唯一参数组合，555个满足最低成交/仓位要求，按2023评分选择第891组。仅导出研究候选，不覆盖原3-1、原3-2、重训版、V1或V2。

## 开发协议

- 2020—2022拟合；2019数据只预热特征；20/22日标签完整结束于2022。训练读取物理截止快照。
- 10份上涨模型×5份止损模型×5档上涨门槛×4档止损门槛=1000。共拟合15份模型，并非1000份不同树模型。全部组合运行前写入candidates.json和protocol.json。
- 模型候选包括叶子数、最小叶样本量、L2、迭代次数、学习率、止损模型类别加权；仍使用原18项价量特征，不改交易与成本假设。
- 2023评分：年化收益−0.5×最大回撤幅度＋0.25×最差季度收益。至少40次成交、平均仓位≥15%；评分并列按Sharpe、年化、编号排序。
- 2024、2025—2026-09-30未进入排名，仅在胜出模型、门槛、源码哈希冻结后评价同一个冠军。不根据这些区间改选其他候选。
- 2023盈利的组合共115个，其中符合成交/仓位条件的38个。555个合格组合的年化中位数为-7.93%；不能将单个冠军理解成普遍稳定有效。

## 校验和执行口径

复用上一轮3-2本地模拟器，预先缓存不可变行情，仍独立初始化每个候选账户。候选1、114、1000与原未缓存回放器的指标和成交逐项核对一致。撮合包括T+1、停牌、涨跌停开盘限制、日量25%容量、单次50000股上限、至少200股买入、费用和公司行动处理，详细近似及限制同上一级README。没有以更乐观的撮合换取速度。

13项校验通过，包括原执行回归、1000组合完整性、训练边界、排名、原文件保护、缓存撮合一致性、冻结后哈希不变及成交约束。导出5000条预测与sklearn的最大误差分别约1.11e-16、2.22e-16。

尚未在SuperMind服务器实际回测；本地编译与预测校验不等于平台运行或实盘认证。平台入口：`supermind_baseline_3_2_search1000_daily.py`，每日频率。研究历史与数据版本局限沿用上级记录。

- results/comparison.csv：冠军与V2四阶段对比；各阶段目录保存逐日资产、成交和参考价差异。
- results/checkpoint.json、progress.json：断点与进度；frozen.json：冠军及冻结哈希；verification.json：校验记录。
