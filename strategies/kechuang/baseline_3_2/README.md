## 保留规则和行为变化

保留主概率0.63、止损概率≤0.50、排序p−0.22×stop、单票目标10%、模型原有持仓上限和每日候选上限；止损7%、盈利24%减半、34%全出、30自然日弱势退出、60自然日硬退出。仍按原先买入后卖出的顺序执行。

3-2日频止损含义是昨日收盘触发、下一交易日开盘尝试卖出。它不能保证恰好亏损7%就成交。开盘跌停、停牌或容量不足时由平台拒绝/部分成交，之后继续按实际持仓处理。

不读取当日日线close、全天volume或持仓last_price来生成当天开盘的退出指令。`SIGNAL_AUDIT`、`EXIT_SIGNAL`、`ORDER_AUDIT`、`EXECUTION_AUDIT`记录数据日期、回调时间、触发价格和成交结果。

除权风控用两次盘前查询中同一历史日期的前复权价格比调整成本基准，避免卖出盈利后broker cost_basis变化被误认为除权。锚点缺失时跳过该股退出信号并报警；缺失行情不会清除账户持仓。平台具体动态复权行为仍需事件日回放核验。重启后缺失原始入场日期时记录警告并使用平台position_days，此时自然日规则不能宣称完全复原，实盘部署仍需持久化状态。

## 研究口径和未完成事项

保留旧模型是为了隔离执行修复的影响。它仍有原数据股票池偏差、止损标签跨年及过滤后计数等历史问题；本版本不是“严格无泄漏重训模型”。

`research_contract.py`提供区间存续股票池、完整行情上的22观测日止损标签、训练截止前截断及累计容量函数。它未接入完整本地重放引擎，也未自动替换训练源码或模型。停牌期间的交易日定义需结合完整交易日历统一；当前函数要求输入为完整日线序列。

重新训练前须补齐包含退市证券的原始数据和状态记录。对历史上涨模型也应按每条标签的结束日期校验切分；仅凭2024-12-01这个固定日期，不能无条件证明所有证券的20条后续记录都结束于2024年。此前“主模型严格没有越界”的判断过强。

已见过的2025—2026结果不能因本次修复重新命名为独立样本外结果，也不自动认定8—9月独立。此次没有重训、没有生成收益指标，没有认证实盘可复制性。需要平台实际编译回测并抽样核验历史证券查询、日频字段、成交和除权事件。
