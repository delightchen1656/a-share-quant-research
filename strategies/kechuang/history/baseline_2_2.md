# 科创2-2：升温防守研究路线

状态：正式基准。平台入口：`../supermind_baseline_2_2_rising_defense.py`。

## 研究目标与逻辑

科创2-2承接历史科创1-3的季度走步熊市概率、熊市软缩仓和下行相关性分散，再增加行业温度门控。行业温度综合一年位置、中期趋势、站上60日均线的宽度、量能、行业联动和龙头强度。

最终规则优先允许行业10日温度上升的候选；若行业温度不低于65、10日变化高于-4且至少55%成分股站上60日均线，也允许小幅降温的强势行业进入。其余排序、仓位、止损、分批止盈和持有期沿用底层模型。

## 尝试过的方向

第一阶段研究十种行业状态：低温复苏、中温加速、宽度扩散、龙头带动、量能点火、联动突破、低位趋势确认、温度持续上升、温度状态机、温度集成与风险配置。

第二阶段收敛为六条路线：

| 路线 | 处理结果 |
|---|---|
| 高温转弱＋极端熊市保护 | 收益线研究，未成为防守基准 |
| 温度概率重排＋高温转弱保护 | 偏进攻，归入历史2-1思路 |
| 行业联动＋高温转弱保护 | 分散改善有限 |
| 升温为主、强势行业小幅降温仍可进入 | 正式采用为2-2 |
| 宽度为主、强龙头升温替代确认 | 条件较宽，未采用 |
| 低温复苏门槛＋温度概率排序 | 稳定性不及最终路线 |

研究结论不是简单追逐最热行业，而是让行业状态决定是否允许底层个股信号开仓。历史2-1偏收益进攻，2-2选择升温防守并作为当前主线。
