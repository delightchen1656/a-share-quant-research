# K线看盘软件

从仓库根目录双击 `启动沪深看盘.cmd`；或执行 `quant_env/Scripts/python.exe -X utf8 -B K线看盘软件/launch.py`。默认端口8766。

- 股票及方向1信号读取本软件 `data/` 内已校验展示快照。公共股票行情在 `K线数据/沪深/`，展示快照与研究白名单独立保存。
- 黄金读取 `K线数据/黄金/`，上证指数读取 `K线数据/指数/上证看盘/`。
- `runtime/` 只存运行日志；原始行情、信号快照和来源证据均不是缓存。
- 方向1研究入口为 `研究尝试/方向1_超跌反弹/`。已停止研究不因目录迁移恢复。
- `auto_update_gold.py` 继续执行既有黄金更新；股票行情统一使用根目录 `tools/daily_market_update.py`。

价格口径、展示范围与研发权限见本目录 AGENTS.md，详细操作见使用说明.txt。
